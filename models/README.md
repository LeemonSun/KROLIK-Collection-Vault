# Модели

Пустой каталог намеренно. Ничего не загружается автоматически. Веса не хранятся внутри исходного git-снимка.

Модель текста и модель зрения — разные возможности. Кандидат общей VLM может обслуживать и текст, и изображение, но его CPU/Vulkan-поддержку нужно реально проверить.

До включения файла: версия/ревизия, SHA-256, лицензия, NOTICE, язык, тип квантования, размер контекста, память, минимальный runtime и независимые тесты. Модель не становится «нашей с нуля» от смены названия или дообучения.
