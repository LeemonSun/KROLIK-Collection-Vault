# KROLIK Collection Vault

Локальная интерактивная dark-fantasy коллекция для Windows. Программа хранит исходники персонажей отдельно от размещений, не перезаписывает утверждённые файлы без команды пользователя и рассчитана на постепенное расширение до сотен персонажей.

## Быстрый запуск на Windows

1. Распакуйте папку целиком.
2. Запустите `START_COLLECTION.bat`.
3. На первом запуске скрипт создаст `.venv` и установит Pillow + pywebview.
4. По умолчанию Vault открывается отдельным нативным окном через WebView2. Если нативное окно недоступно, приложение переключается на обычный браузер.
5. Все рабочие данные создаются рядом с программой в `KROLIK_COLLECTION/projects/main_collection/`.

Интернет после установки зависимостей для обычной работы не требуется. Сервер слушает только `127.0.0.1`.

## Windows EXE

`BUILD_WINDOWS_EXE.bat` собирает `dist/KROLIK_Collection_Vault.exe` через PyInstaller. Сборку Windows EXE нужно выполнять на Windows: обычный PyInstaller не является кросс-компилятором. Данные коллекции остаются отдельной папкой рядом с EXE и не зашиваются в исполняемый файл.

## Что уже работает

- реестр стартовых 82 персонажей с постоянными ID;
- 96 стартовых ячеек и динамическое добавление этажей; проверено расширение до 504 ячеек;
- виртуализированный Canvas: отрисовываются только видимые ячейки;
- три уровня качества изображения: thumbnail 256, thumbnail 768, оригинал на близком масштабе;
- ограниченный LRU-кэш изображений, чтобы длительное перемещение по большой базе не раздувало память;
- 8 процедурных типов конструкций ячеек с независимым задним и передним слоем;
- персонаж хранится отдельным слоем и не вшивается в фон;
- перемещение, масштаб, X/Y, поворот, отражение, прозрачность, глубина;
- сохранение пропорций по умолчанию; раздельное X/Y возможно только после ручного отключения блокировки;
- выравнивание персонажа по полу;
- Ctrl+Z / Ctrl+Y для трансформаций текущей сессии;
- блокировка персонажа, ячейки и размещения;
- SQLite WAL, автосохранение состояния интерфейса, журнал событий;
- автоматические и ручные резервные копии;
- консистентный ZIP проекта: в архив попадает SQLite-снимок, а не живая БД вместе с WAL;
- встроенная диагностика целостности SQLite, потерянных медиа и доступности записи;
- одиночный импорт PNG/JPG/WebP/TIFF;
- массовый импорт нескольких файлов;
- drag-and-drop файлов прямо на окно Vault;
- импорт/экспорт переносимого пакета персонажа `.kchar`;
- `.kchar` переносит изображения, метаданные, камеры и позы;
- дедупликация одинаковых файлов по SHA-256;
- история версий и отдельный менеджер версий с выбором основной;
- ручное утверждение: статус `Утверждена` никогда не ставится автоматически;
- мягкий редактор альфа-маски: скрыть / вернуть / размер / мягкость;
- автоматическое удаление близкого к однотонному фона как отдельная версия;
- библиотека камер: имя, yaw, pitch, связанная версия изображения;
- библиотека поз: текущая трансформация + камера + версия изображения;
- применение сохранённой позы к выбранной ячейке;
- idle-анимация слоя персонажа: лёгкое покачивание, наклон и дыхание без изменения исходника;
- режим «базы», скрывающий редакторские панели;
- мини-карта и свободная камера;
- пользовательский фон хранилища;
- экспорт PNG текущего вида, CSV прогресса, ZIP проекта и `.kchar` одного персонажа.

## Импорт листов — специально для больших подборок

Кнопка `Лист / сетка` загружает исходный лист целиком и открывает редактор сетки.

- стартовая сетка 10×5, её можно изменить;
- внутренние линии сетки двигаются мышью;
- клик по клетке включает или исключает её;
- кадры только с лицом или неудачные обрезки можно просто исключить;
- выбранным клеткам назначаются постоянные ID;
- кнопка автоматического назначения использует свободные ID из реестра;
- каждая вырезанная клетка сохраняется отдельным PNG как новая версия;
- в БД сохраняются исходный лист, строка, столбец и точные координаты crop;
- исходный лист остаётся неизменным.

## Управление

- колесо мыши — масштаб;
- перетаскивание пустого места — камера;
- клик по ячейке — выбрать;
- двойной клик — приблизить ячейку;
- перетаскивание персонажа — точное размещение;
- стрелки — микроперемещение;
- Shift + стрелки — более крупное перемещение;
- Ctrl+Z / Ctrl+Y — отмена / повтор;
- Esc — выход из режима базы;
- двойной клик по персонажу каталога — поместить его в выбранную ячейку.

## Что пока сознательно НЕ выдаётся за готовое

Текущая сборка уже является рабочим Vault/редактором, но финальная цель больше. Ещё не реализованы настоящий 2D skeletal rig с костями/деформациями частей тела, автоматическая реконструкция новых ракурсов, полноценная 2.5D/3D модель, сложная анимация рук/волос и Deep-Zoom экспорт всей архитектуры в тайловую пирамиду. Таблицы и интерфейс поз/камер заложены так, чтобы эти системы добавлялись поверх текущего проекта без смены формата персонажей.

Программа также не генерирует и не дорисовывает отсутствующие части персонажа сама: исходник остаётся первичным источником.

## Проверки текущей сборки

На текущем коде выполняются:

- 11 backend-тестов;
- SQLite integrity check;
- импорт и дедупликация изображений;
- блокировки;
- резервные копии;
- перенос `.kchar` с позами/камерами;
- ручная сетка листа и crop;
- расширение до 504 ячеек;
- HTTP smoke test `health/bootstrap/diagnostics`;
- headless UI smoke test: 82 элемента каталога, редактор листа 5×10, лаборатория поз/камер, без JS page errors.

## Главное правило проекта

Оригинал изображения никогда не изменяется трансформациями размещения. Масштаб, позиция, поворот, отражение, маска, выбранная версия, поза и камера хранятся отдельно. Новая обработка создаёт новую версию.
