# Упаковка

Сейчас готовится только ZIP исходников. Windows export preset приложен как заготовка; экспорт требует соответствующих официальных templates той же версии Godot.

Будущий установщик: приложение + веса/голос + лицензии + uninstall. Сохранения отдельно в профиле пользователя. Обновление не удаляет заметки и настройки. Модельные пакеты должны иметь manifest, хеш и понятное управление диском.

Steam AppID, publisher, установщик, подпись и депоты пока не заданы. Не использовать демонстрационный AppID другого продукта. Файлов запуска GitHub Actions нет, как требует пользователь.
