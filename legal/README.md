# Правовой реестр

Оригинальные файлы проекта — разработка для владельца проекта. Название издателя и конечная лицензия собственного кода не утверждены. Не приписывать авторство сторонних компонентов владельцу проекта.

В архиве исходников не вложены Godot runtime, llama.cpp, модели, шрифты или сторонние анимации. Godot используется для разработки; копия его LICENSE вложена для подготовки будущей дистрибуции. Полный runtime в дальнейшем потребует всех уведомлений его включённых компонентов, а не только одного LICENSE.

models.json содержит кандидатов и пустой список реально включённых моделей. components.json не является полным SBOM будущего бинарника. При добавлении каждой зависимости фиксировать версию, хеш, происхождение, лицензию, NOTICE и изменения.

Указание MIT/Apache на репозитории не заменяет проверку конкретного готового архива и весов. Пользовательские данные, коммерческие ключи, снимки экрана и материалы неизвестного происхождения не входят в поставку.
