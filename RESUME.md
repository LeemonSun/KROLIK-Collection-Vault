# Быстрый вход: Companion

Репозиторий: `LeemonSun/KROLIK-Collection-Vault`, ветка `main`. GitHub только хранит файлы; работа и проверки локально.

1. Прочитать этот файл и выполнить `python3 tools/resume.py status`. Не перечитывать весь архив документации.
2. Если среды/скрипта нет или копия старая: через GitHub connector получить `tools/resume_bridge.js` из main, один раз прочитать и выполнить его в functions.exec. Он восстанавливает только код из компактной проверяемой капсулы. Начало функции: `await companionResume({action:'bootstrap'})`.
3. Для изменений загрузить только нужные файлы из карты ниже. Картинки/шрифты получать через bridge с `action:'assets', group:'test'` только когда нужны соответствующие проверки. Сборки, картинки-референсы и большие модели не скачивать просто для продолжения.
4. Перед паузой обновить `recovery/session.json`, выполнить `python3 tools/resume.py snapshot`, затем bridge `action:'checkpoint'`. Не ждать окончания большого этапа, чтобы сохранить незавершённую работу; честно отметить WIP и непроверенные места.

Исходники: **0.3.4-dev**, не выпущено. Добавлены проверяемые ответы о себе, более точная роль и параметры non-thinking, адаптивный лимит длинного ответа, пересчёт границ монитора. На настоящей модели новые формулировки ещё не оценены; веса в среде не закэшированы. Пользователю НЕ выдавать 0.3.3 как содержащую эти изменения.

Сейчас: **0.3.3**, один винно-серебристый стиль: новый чат, собственное меню действий, адаптивная панель и процедурный idle. Главное окно = персонаж (исправление 0.3.2 сохранено); taskbar/tray/recovery. Windows-проверка ожидается. Full ZIP передан отдельным вложением; sandbox-ссылки у пользователя не открываются. Модель, ASR, web reading и body rig этим проходом не добавлены. Готовых body clips 0. Пиксели и переключатели тем отложены.

Карта: чат — `src/ui/chat_view.gd`; запуск — `src/ui/bootstrap.gd`; персонаж — `src/desktop/companion_window.gd`; ИИ — `src/app.gd`, `src/runtime/local_runtime.gd`; обновления — `tools/make_patch.py`; продуктовые требования — `docs/PRODUCT_DIRECTION.md` (читать только по задаче).

`PROJECT_STATE.md` и `docs/HANDOFF.md` — подробности, не обязательное повторное чтение каждой сессии. Не восстанавливать среду целиком и не повторять все тесты без причины. Не перезаписывать конфликтующие локальные правки. Сброс scratch возможен; долговременная точка восстановления — капсула и файлы в GitHub.
