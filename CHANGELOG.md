# 0.11.0 — действия, маскот, файлы и компактная память

- До четырёх заданных пользователем шагов по выбранному окну; подтверждение/preflight/проверка результата каждого. Отмена остатка при ошибке, смене окна или неподтверждённом итоге.
- Точные уникальные select/expand/write идут без загрузки модели. Перед холодной загрузкой ИИ проверяется запас доступной RAM.
- 26 процедурных состояний, три коротких эффекта, реплика рядом с персонажем, движения к свободному месту возле окна задачи.
- Шесть недавних пар диалога, отдельный фактический режим, более короткий контекст, мягкий sampling, удаление шаблонных хвостов и ограниченный casual fallback при зацикливании.
- Выбранные UTF-8 текстовые конфиги до1МБ: preview, единственная точная замена, backup/index, SHA-проверка, rollback через preview, защита от устаревшей записи и паузы.
- Явные upsert/delete факты ≤1024записи/512КБ, ограниченное retrieval; трёхстороннее объединение с конфликтами для будущего Cloud.
- Steam Cloud изучен и спроектирован; фактической синхронизации ещё нет. XLSX/универсальный автономный агент и гарантии фактической точности не заявлены.

# 0.10.0 — чтение выбранного окна

- Явное чтение доступного текста окна через UIA и листовые видимые TextPattern ranges; без постоянного наблюдения и дополнительной модели.
- Вопросы RU/EN/zh-Hans с проверяемыми ID источников и дословными выдержками, отдельный отказ при нехватке данных.
- Одноразовый контекст: удаление из receipts/HTTP, исключение вопросов и ответов из истории. Отмена и смена цели очищают контекст.
- Кнопка чтения в чате, статусы, блокировка параллельных операций, прокрутка к началу нового ответа.
- Все ошибки HTTP теперь освобождают исходный запрос. Чтение снимает старое подтверждение действия.
- Модели и 16 состояний маскота прежние; Windows приёмка впереди.

# Изменения

## 0.5.0-leemon-preview — 27.10.2026

Новый лимон Leemon и один графитово-янтарный стиль. Один shared master, шесть частей cutout-рига, восемь процедурных состояний с реакциями; старая девушка исключена из экспортированного PCK. Офлайн-часы (597 IANA-зон/2039 aliases), сохраняемые напоминания/отмена, явный перевод буфера только своим локальным worker с очисткой исходника. Лимит CPU половина логических процессоров, минимум 1, максимум 8. Адаптивная навигация в коротких окнах и актуализация reminders. Новый EXE/icon+PCK delta с SHA, backup/rollback и защитой mixed versions. Чистая Windows ZIP и GIF фактического рига. Источники и восстановление сохранены после отключения среды.

13 групп checks, 76 native X11, 11 exported-content, 21 executor и 8 update scenarios PASS. Windows native ожидает приёмки. Qwen3-1.7B не заменён; научная точность ограничена. Нет ASR/custom voice/VLM/page reader/готовых рисованных клипов. Веса пока скачиваются отдельно, public Steam gate закрыт.

## 0.4.0-functional-preview — 27.10.2026

Обычные команды запуска приложений из меню «Пуск», известных папок и HTTP(S) ссылок; отдельный Windows-исполнитель с nonce, таймаутом/отменой и различением запроса запуска и найденного окна. Языковая модель не исполняет код и не является источником успешного результата. Backstop распространённых выдуманных действий. Опциональная история 100 сообщений/256 КиБ, реальный перезапуск, удаление истории и отдельных заметок; retrieval ручных заметок. Настоящий подсчёт контекста через локальный worker с удалением старых полных пар. Нагрузка app+owned AI; активный лимит 60 FPS и idle 24/30; исправлен двойной tint, перетаскивание обновляется раз за кадр; cleanup только известных 0.3.2/0.3.3 патчей по SHA с архивацией backup. Полный чистый ZIP, модель и профиль в AppData сохраняются.

Весы/rig/ASR/custom voice/vision/page reader не добавлены. Real-model оценка в этом проходе не повторена. Native Windows приёмка ожидается.
