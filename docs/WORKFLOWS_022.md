# Leemon 0.22 — desktop task entry points

Primary direction remains a general adaptive agent in existing applications, not per-app models. This pass supplies missing entry points into that loop and two lightweight deterministic workflows. No production model or worker resource policy changed.

## Implemented

- RU/EN/zh command boundary for existing browser tab search. Example: «открой браузер и найди мне там во вкладках саунклауд», `find tab SoundCloud`, `打开标签页SoundCloud`. It searches already open accessible browser chrome; it does not launch a missing browser or create a website tab. Known Russian SoundCloud aliases normalize locally. Other arbitrary misspellings are not guaranteed.
- UIA traversal explicitly skips Document subtrees, including page text, passwords and their descendants. Up to24 visible top-level windows considered, up to3 supported browser windows scanned,200visited/90recorded nodes per window,8levels,2500ms soft traversal budget. Supported process names: chrome/msedge/firefox/opera/brave/vivaldi/browser. Providers may omit tabs, exceed a single call timeout, or require accessibility settings. Partial/no-match is not proof that no tab exists.
- A unique substring match is selected directly using SelectionItemPattern. Multiple matches require a transient choice card. Titles/descriptors stay in transient memory/ephemeral UI messages and are never submitted to a model or saved in chat history. Thirty-second choices are invalidated by new chat submissions or Stop; expired selection is rejected. No cookies/profile databases/DevTools ports/browser extension used.
- Before selection, hwnd/PID/process start time and fresh RuntimeID/name/role/AutomationId/ancestor descriptor must match. Selection state and foreground hwnd are checked separately. A selected background tab is reported honestly, not as a focused browser. No automatic playback/login/page interaction.
- Explicit `открой Proton VPN и нажми Подключить` / `launch Notepad and click New` / `启动记事本并点击新建` launches via the existing installed-app catalog, then hands the verified window identity and literal remaining goal into the existing bounded shared UIA agent. Existing per-step review and result verification remain. A successful process start without a verified visible window does not advance the chain. This is not universal VPN client support; an invoked button is not a connected-status receipt.
- `включи впн`, `connect vpn Work`, `连接VPN` use existing Windows VPN profiles only. Auto-choice only when exactly one profile exists; otherwise user must name one. Get-VpnConnection user/all-user inventory, locally sourced fixed rasdial.exe/phonebook, saved sign-in only, no credential gathering. ConnectionStatus must say Connected before success. Max32profiles; rasdial child waits8s then stops, four bounded status reads. Unsupported/missing/ambiguous/timeout/unverified outcomes remain distinct. No third-party client config editing, provider installation, routing edits or kill-switch promise. A changed or disabled VPN service may fail.
- `открой Steam и включи впн Work` / `open Steam and connect vpn Work` / `启动Steam并连接VPN` advances only after a visible app receipt. Cancellation prevents later stages; it does not undo a connection request already issued to Windows. The helper transport terminates its PowerShell process on Stop; an already started rasdial/Windows service operation may still complete independently. No promise of transactional cancellation.
- One graphite/amber task card, lightweight stronger title typography using the existing licensed Noto font, compact tab selector and distinct work state. Input/Stop/choice buttons remain visible at320×280,360×320,460×560 in native X11 fixtures across3locales. No extra theme, no new heavy model, no continuous tab/screen watcher. Existing idle unload and one worker remain.

## Limits and required acceptance

This environment cannot execute Windows UIA, PowerShell5.1, real browsers/VPN, games or hardware FPS measurements. Linux PowerShell nonce transport and synthetic UIA traversal do not prove Windows task success. Existing2B semantic planning/reasoning weaknesses remain; no claim of improved IQ or universal unattended PC control. UI is a private preview, not a Steam-ready release.

Acceptance: test an existing SoundCloud tab in each target browser, duplicate titles, hidden tabs, elevated/inaccessible browser, foreground denial, tab renamed/deleted before choice, Stop during scan, launch failure/slow startup, existing Windows VPN with/without saved credentials, multiple profiles, failure/timeout, and actual game FPS/RAM/CPU with quiet settings. Never test on destructive files or external messages first. Keep confirmation gates for shared agent actions.
