# Leemon 0.15: bounded adaptive selected-window loop

Choose an existing window with the window button. Enter `agent: <goal>` (Russian `агент: <цель>`, Chinese `窗口任务: <目标>`), or use ✦. This delegates at most four UIA steps for four minutes. Each next step uses a fresh snapshot and verified receipts. Each actual step still requires the existing approval and fresh preflight. Cancel revokes delayed continuations.

This is a narrow foundation, not a universal autonomous agent. Available navigation is select/expand; text must appear verbatim in the original goal. Invoke still requires explicit original-goal button wording and exact label. No arbitrary coordinate clicks, generated documents, hidden browser control, automatic privileged changes or continuous weight training. Model may stop without reaching the goal; no overall success is asserted merely because a control changed. In-session receipts are not persistent learned skills.

## Chat

Copy icon beside chat status copies all retained visible messages in chronological order. Also: `copy whole chat`, `скопируй весь чат`, `复制全部聊天`. It copies ephemeral visible messages only on explicit request and does not turn them into notes. Max100 retained messages; older discarded messages cannot be recovered. Truncation is disclosed and optionally persisted with history. Max4MiB; overlarge transcripts are refused rather than silently shortened. Clipboard is local; no upload.

Self-knowledge routes reported capability/update/export/limitations questions to localized actual app facts. The model is not fine-tuned by this patch. Free conversation may still be inaccurate. Root of a literal number uses the existing bounded calculator.

Future character/voice concepts: VISUAL_IDEAS.md, no new character assets in this patch.
