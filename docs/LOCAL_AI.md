Установка только по явной кнопке. Движок и модель скачиваются с официальных HTTPS-адресов; результаты модели не могут задать URL. HTTPRequest пишет на диск с ограничением размера. Большая SHA-проверка выполняется в отдельном потоке. ZIP распаковывается по точному списку имён и хешей. Установочные файлы/данные не публикуются в git. Отмена не запускает частично скачанный worker; продолжения загрузки с середины пока нет.

Место: user://local-ai-v1, обычно %APPDATA%/Godot/app_userdata/Companion Foundation/local-ai-v1. Права администратора не нужны. После установки можно отключить сеть: чат работает через 127.0.0.1. Браузерный поиск всё ещё требует интернет.

У приложения один принадлежащий ему процесс, случайный локальный порт и временный токен, проверка авторизованного /v1/models, запуск с фиксированными аргументами массивом, без shell. Отключены web UI, GPU fallback, polling; один слот и ограниченный CPU. Это граница процесса своего приложения, не защита от владельца ОС, который может менять свои файлы.

Модель хешируется при установке; при старте проверяются receipt, размер/mtime модели и все исполняемые файлы/библиотеки. Изменённый пакет требует повторной проверки/установки. Полный вес не перечитывается на каждый короткий запрос. Файлы и ключи не отправляются в сеть для inference. Модель не имеет инструментов, доступа к диску/браузеру/экрану или выполнения команд.

Профили задают CPU threads, 2048–4096 контекста и лимит ответа; история укладывается консервативным UTF-8 бюджетом с удалением старых целых пар. Слишком длинный текущий запрос отклоняется с объяснением. Настройка профиля применяется к worker при следующем запуске. При простое процесс выгружается через 120–300 секунд; первый вопрос после сна сохраняется в очередь, worker стартует. Пауза/выключение/выход останавливают процесс. Нет скрытого постоянного обучения; память разговора — короткая RAM-история.

Реально проверены на Linux: тот же pinned CPU release и вес, авторизация, ответы RU/EN/zh-Hans; Godot сам запускает worker, проходит readiness, отправляет реальный запрос, выгружает по простою, перезапускает и отменяет запуск. Отдельный Windows runtime скачан и сверён с опубликованным SHA, но не исполнен здесь. Это не подтверждает работу на любом Windows-ПК или точность ответов. Синтетические ответы показали ошибки формулировок — baseline нужно сравнивать с более сильными пакетами. Данные по скорости — разовые, не минимальные требования.

Общее VLM-понимание экрана, исследование страниц, память предпочтений и инструменты остаются следующими этапами. Мультимодальные кандидаты сохраняются в manifests/models.json; текущий текстовый пакет не выдаётся за VLM.
