## Measured COCO ground-truth accuracy

A separate benchmark runs the production DWPose path against the compact COCO fixture shipped by MMPose tests. Ground-truth keypoints were human annotations; they are not generated by KROLIK or by DWPose.

Measured CI result:

- people/samples: 4
- visible evaluated keypoints: 63
- failed samples: 0
- mean normalized joint error: `0.014758`
- median normalized joint error: `0.010237`
- mean pixel error: `5.809 px`
- maximum normalized error: `0.055410`
- PCK@0.05: `0.968254` (96.8%)
- PCK@0.10: `1.000000` (100%)

The normalized error uses the annotated person bbox diagonal, so the score remains comparable across image sizes.

This compact four-person corpus is a regression baseline, not a claim that arbitrary anime/fantasy art has the same accuracy. Domain-specific QA on a broader art corpus remains required later.

## Remaining limitations

A2 can be treated as a verified production baseline once the packaged Windows importer also passes its real-DWPose CI gate. This does not eliminate later Phase-F QA requirements:

- anime/fantasy domain corpus with unusual proportions/clothing/occlusion;
- multi-person source-image UX (the current character import path assumes the selected/cutout character bbox);
- measured GPU-provider behavior on target Windows hardware;
- manual correction UX in the final graphical editor;
- conservative cutout/matting review for difficult backgrounds.

No rig schema bump was needed: the existing portable 15-joint KROLIK contract remains unchanged.
