Leemon {VERSION} — личная тестовая сборка Windows x64

Распакуй всю папку и запусти Companion.exe. Не запускай EXE отдельно от Companion.pck. Персонаж появляется на рабочем столе; настройки открываются из его меню. Старую копию приложения перед запуском новой закрой. Модели/заметки из профиля Windows не удаляются.

Возможности → Мозг Лимона:
1. Базовая Qwen3.5 2B использует прежнюю установку. Если её нет — «Установить базовую модель».
2. Для кандидата выбери название → «Страница модели» → Quantizations. Скачай один полный GGUF нужной instruct-модели (обычно Q4_K_M; Gemma QAT может быть Q4_0). Нужен GGUF, не safetensors, не mmproj и не split-часть.
3. «Подключить GGUF» → выбери скачанный файл → дождись проверки. Файл остаётся на месте; не перемещай и не удаляй его после подключения.
4. Если нужно — «Подготовить запуск» установит проверенную среду, без второй базовой модели. Интернет нужен для скачивания; разговор после установки локальный.
5. Переключай кандидатов в том же списке. Старый worker останавливается, новый запустится при запросе. Контекст разговора сбрасывается, видимая история остаётся.

Сравнение: включи «Сравнение без личной памяти». Для нового блока нажми «Новый контекст разговора». В этом режиме обычный чат не получает личные заметки/факты, бюджет ресурсов одинаковый:2CPUthreads/4096context. «Копировать всё» в чате сохраняет модель и время её разговорного ответа (без загрузки модели). Большие блоки вопросов лучше делить, чтобы не упереться в ограничение длины ответа.

Открытие браузера/калькулятора и точное создание текстового файла могут выполняться алгоритмами без нейросети. Они проверяют приложение, а не интеллект модели. Примеры: «открой калькулятор», «посчитай в калькуляторе100*10», «открой блокнот и создай файл с надписью1». Существующие файлы меняются через просмотр и подтверждение. Универсальное редактирование любого приложения ещё не готово.

13профилей — это возможность личной проверки, не гарантия качества или запуска любого стороннего GGUF. Импорт сверяет формат/семейство, вычисляет локальныйSHA; это не проверка происхождения или лицензии скачанного файла. У LFM и Gemma3 собственные условия.
Изображения подключены только к прежней базовой2B. Остальные профили пока текст+доступные инструменты; чужой projector к ним не подключается. Для9B/E4B/7B нужно больше памяти. Пока модели проверяются наCPU; GPUпрофиля в этой сборке нет.

Сборка не подписана и не является Steam-релизом. Проверки здесь выполнены наLinux/Godot; WindowsEXE, микрофон и качество новых моделей на реальномПК ещё требуют проверки.
