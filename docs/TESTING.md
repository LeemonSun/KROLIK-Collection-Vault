# Проверки

## Уже исполняемые

tools/verify_project.py: JSON, полнота трёх локализаций и placeholders, относительные пути, состояния модулей, отсутствие весов/секретов в исходной поставке.
tests/test_core.gd: команды RU/EN/ZH, границы ввода, память и повреждённый файл, состояние/пауза/отмена, таймер, профили, политика, свежесть/область наблюдения, общий тяжёлый бюджет.
tools/test_http.py + tests/test_http.gd: настоящий локальный HTTP-обмен с собственным fixture, Unicode, ошибки, запрет редиректа, верхняя граница ответа, отмена, запрет параллельного запроса и обход прокси окружения.
--ui-smoke: создание всех четырёх страниц на трёх языках.

Проверки Godot могут выводить ошибки в stderr при нулевом exit code; проверять и код, и журнал. Реальные результаты текущего прогона записываются в reports/VALIDATION.md.

## Не подменять будущие проверки

tests/scenarios — будущие приёмочные случаи, не распознанные экраны. Не проводились: качество зрения/голоса/перевода, тесты миллионов игр, реальная Windows, FPS и CJK-типографика, встроенный llama.cpp worker. Проверка дерева UI без дисплея не заменяет визуальную проверку.

## Будущая матрица

CPU/RAM/GPU и драйверы; Windows 10/11; RU/EN/ZH имена файлов и пользователя; плохой/занятый диск; сон и повторный запуск; DPI и несколько мониторов; захват недоступен; игра забирает VRAM; отсутствие микрофона; смена окна до действия; prompt injection в тексте страницы; неизвестное приложение; сбой worker и отмена.
