# Чекпоинты KROLIK

У проекта теперь три независимых уровня восстановления:

1. **Git/GitHub-коммиты** — история исходников и именованные milestone-ветки `checkpoint-*`.
2. **Локальные ZIP-чекпоинты исходников** — `MAKE_CHECKPOINT.bat` создаёт атомарный архив в соседней папке `KROLIK_CHECKPOINTS` и SHA-256 рядом с ним.
3. **Бэкапы пользовательской БД** — Vault отдельно сохраняет SQLite-бэкапы коллекции. Исходные изображения не перезаписываются.

## Обычный ручной снимок

Запустить `MAKE_CHECKPOINT.bat`.

По умолчанию архивируются код, web UI, Godot runtime, тесты, документация и небольшие ассеты. Кэш, `__pycache__`, `.pytest_cache`, `.git` и живая папка `KROLIK_COLLECTION` не копируются, чтобы снимок исходников оставался безопасным и компактным.

## Полный снимок вместе с данными коллекции

```bat
py -3 tools\make_checkpoint.py --label full_data --include-data
```

Использовать только при необходимости: коллекция может быть очень большой.

## Политика разработки

Перед изменением формата данных, рига, skinning, runtime-world или миграций БД создаётся **pre-change checkpoint**. После прохождения тестов создаётся **stable checkpoint**. По умолчанию хранится 20 последних ZIP-снимков; удаляются только старые чекпоинты, а не пользовательские данные.

В каждом ZIP есть `_checkpoint_manifest.json`, а рядом лежит sidecar `.json` с SHA-256. `LATEST.txt` указывает последний снимок.
