# Leemon 0.14 — общие инструменты помощника

Техническая цель: единый помощник для разговора, учёбы, документов, расчётов и работы с Windows. Не отдельная модель на приложение. Одна тяжёлая задача, общий ресурсный бюджет, проверяемые инструменты и явные границы. Художественный редизайн отложен.

## Реализовано

- Calculator: `/calc sqrt(81) + 2^3`, «посчитай (2+3)*4», “what is 2+3”. Собственная ограниченная грамматика, без eval/Expression.execute/shell. Скобки, + − × ÷, степени, проценты, sqrt/abs/sin/cos/ln/log10, pi/e. Степень правоассоциативна, -2^2 = -4; sin/cos в радианах, % всегда делит на100. До256символов/96токенов/16уровней вложенности. Double-арифметика приблизительная; это не CAS и не точные денежные расчёты. Деление на0, неверная область и переполнение отклоняются.
- Units: «переведи 2.5 км в м», “convert 10 MB to MiB”, “换算 2.5 千米 到 米”. Явные единицы длины, массы, времени, объёма, данных, температуры, давления и скорости. Несовместимые размерности и температура ниже абсолютного0 запрещены. MB и MiB различаются; неизвестные единицы не угадываются. Валютные курсы не выдумываются.
- Windows: «открой настройки звука», “open settings display”, “打开设置 声音”. Только фиксированный список ms-settings URI без параметров/произвольных команд. Открытие не означает изменение настройки: ответ сообщает лишь передачу команды, не проверенное появление окна. Значения Windows не изменяются. Доступность страницы зависит от версии/редакции Windows. Настоящее исполнение требует Windows-приёмки.
- Public page: «прочитай страницу https://…», “read page https://…”, “读取网页 https://…”. Явный HTTPS URL; без browser cookies, Authorization, POST, входа, выполнения JavaScript/форм или открытия вкладки. DNS в асинхронной очереди; все возвращённые адреса проверяются; сокет получает выбранный публичный IP и TLSOptions.client с исходным hostname. Локальные/служебные/transition диапазоны, credentials, нестандартные порты и редиректы отклоняются. IPv6 проверяется консервативно; некоторые легитимные адреса будут отклоняться.
- Текст страницы: HTTP200, UTF-8 HTML/plain, identity encoding, явный Content-Length либо chunked; до256КиБbody/20секунд. Ограниченные выдержки до12×300символов с URL и временемUTC. Это не полный browser rendering и не проверка истинности информации. HTML удаляется как текст; scripts/styles/forms не исполняются. URL/выдержки ephemeral, не добавляются в сохраняемую историю/session turns, и не поступают в LLM как инструкции. Автоматический поиск, Q&A по странице и исполнение гайда пока отсутствуют. Пользователь выбирает URL; сайт получает обычный GET и IP пользователя. Это не гарантия отсутствия побочных эффектов у произвольного сервера.

Все инструменты проходят Router → ToolPolicy → реальный executor. В очередь обычного чата они не попадают. Калькулятор, единицы и чтение страниц не запускают inference. Стоп/пауза отменяют чтение и очищают resolver/socket/body. Статусы отражают этапы запроса и не требуют модели.

## Проверки и честные ограничения

`test_utilities014.gd`: арифметические приоритеты/Unicode/ошибки/лимиты, единицы/размерности/температура/MBvsMiB, реальный Router/App без inference, разрешённые WindowsURI, URL/IP/header/excerpt gates.

`test_public_transport014.gd`: подменённый транспорт, реальная машина polling; fixedIP/TLShostname, отсутствие credentials, отмена, redirects, bodybudget и ephemeral source.

`tools/test_public_tls.py` + `test_public_tls014.gd`: независимый локальный HTTPS-сервер с временным ключом/сертификатом, реальные Godot HTTP/TLS sockets, Content-Length/chunked, redirect и oversized body. Только test adapter направляет publicIP в localhost. Этот adapter и ключи не входят в пакет. Счётчик запросов на стороне Python проверяет Host/пути/отсутствие redirect-перехода и cookies.

Внешний DNS рабочей среды недоступен: Godot и независимый Python getaddrinfo не разрешили chatgpt.com/raw.githubusercontent.com. Поэтому успешная загрузка настоящего публичного сайта здесь НЕ подтверждена. На Windows нужны отдельные internet/proxy/certificate/IPv6 проверки. Гарантия безопасности всех сайтов не заявляется; TLS revocation/pinning не поддерживаются самим используемым Godot API. HTML extractor ограниченный, не полноценный HTML5 parser. Header buffering происходит внутри HTTPClient, собственный предел body не является строгой квотой памяти всей сети.

## Копилка и общий план

`research/component_backlog.json` — 21 запись, явные роли/лицензии/ресурсные группы/условия интеграции. Это не исполняемый download manifest. Дополнение к TECH_STACK_013: SymPy(BSD) для символической математики; SQLite core(public domain)/FTS для локального индекса; multilingual-e5-small(MIT по карточке) для сравнения смыслового поиска. Ничего из новых кандидатов не установлено автоматически. Вес каждой модели/голоса/конверсии и зависимости проверять отдельно.

Последовательность дальнейшей техники:

1. Windows-приёмка UIA, system pages, DPI, lock/reparse, микрофона и настоящего HTTPS; замеры quiet/standard на слабом/среднемПК.
2. Ограниченный общий planner: явная цель → источники/наблюдение → typed tool proposals → подтверждение значимых эффектов → проверка результата → остановка/откат. Текст сайта/файла не может назначать права. Не генерировать shell/registry scripts из произвольного текста.
3. Учёба: точные числовые/символьные инструменты и объяснения с источниками; затем выбранные локальные PDF/DOCX с индексом. База знаний по умолчанию не сканирует весь диск. Не считать keyword PASS доказательством научной точности2B.
4. Windows-настройки: типизированные операции с чтением текущего значения, предпросмотром, резервной копией/обратной операцией и проверкой. Открытие settings page — лишь текущая основа, не выполненная настройка. Автоматически отключать защиту/обновления или массово менять систему не нужно.
5. Речь/OCR: единый компактный runtime там, где оправдано, проверенные голосаRU/EN/zh. CPU fallback, одна heavy job, выгрузка. Браузер — явный профиль/сессия, источники и подтверждение отправки.
6. ПродуктSteam: всё обещанное для base purchase приезжает с установкой; собственныйAppID, depots, local data migration/rollback, privacy/permissions и опциональныйCloud. Дизайн/анимации затем полируются на устойчивой технике.
