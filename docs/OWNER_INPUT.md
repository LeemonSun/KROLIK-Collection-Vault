# Что нужно от владельца

Ничего из списка не блокирует текущий фундамент. Без ответа используются только рабочие обозначения.

| Решение | Что требуется от тебя | Что я могу сделать сам |
| --- | --- | --- |
| Название программы | Утвердить название и имя разработчика для страницы Steam | Предложить названия, подготовить оформление; отдельно проверить доступные совпадения |
| Первый персонаж | Выбрать девушку, мужчину, робота/маскота; 2–3 ориентира по внешности и характеру | Создать собственные концепции, структуру модели, набор анимаций; генерация изображений только после прямой просьбы |
| Голос | Пол/тембр, спокойный или эмоциональный; нужно ли обращение «господин» | Подобрать модели, сравнить качество и права; подготовить собственный голос при разрешённом исходнике |
| Автономность | Нужны ли вообще добровольные сетевые функции | Базу сделать офлайн, сеть отключить по умолчанию |
| Нижняя граница ПК | Пример самого слабого компьютера друзей: CPU, RAM, GPU | Выбрать профили, подготовить бенчмарк; твой известный ПК — 7800X3D/32 ГБ/RX 6650 XT |
| Размер установки | Готов ли к нескольким ГБ, предпочтителен ли отдельный HD-пакет | Разделить базовый и улучшенный комплекты без ручных зависимостей |
| Приоритеты v1 | Выбрать первые 3–5 реальных задач, которые важнее всего | Составить общий механизм восприятия и набор тестов, не систему под каждую игру |
| Наблюдение | По умолчанию только по вопросу или постоянное наблюдение после включения | Реализовать выбор окна/области, паузу и экономию ресурсов |
| Действия на ПК | Только советы или также выполнение по просьбе | Политика инструментов, предпросмотр значимых действий, проверка результата |
| Steam | В будущем аккаунт издателя, доступные реквизиты и утверждение цены/страницы | Подготовить пакет и черновики; не требуются для фундамента |
| Языки | Подтвердить китайский: пока zh-Hans/путунхуа | Подготовить тексты RU/EN/ZH, словари и тесты; перед релизом желательна проверка носителем |
| Материалы | Передать только те материалы, которые хочешь использовать и на которые есть права | Создать свои материалы или выбрать допустимые готовые |

Названия ИИ и библиотек тебе выбирать не обязательно: это могу сделать я по измерениям, лицензиям и качеству. От тебя в первую очередь нужны продуктовые предпочтения и минимальное железо.

Если нужен узнаваемый голос реального диктора, понадобится согласованное разрешение на синтез и распространение. Юридические/платёжные действия от твоего имени не выполняются без отдельной инструкции.
