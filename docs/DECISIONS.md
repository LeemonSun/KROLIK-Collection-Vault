# Принятые решения

- Godot без .NET: один стандартный runtime и лёгкий 2D-профиль.
- Своя предметная логика, сторонние движки используются с сохранением лицензий.
- В первой поставке исходников нет весов: не раздувать архив и не объявлять кандидата проверенным пакетом.
- ИИ по умолчанию отсутствует явно; демонстрационный текст не притворяется ответом нейросети.
- Универсальное восприятие: VLM + OCR/доступность + история, а не обязательный плагин каждой игры.
- Рабочая временная запись заметок — JSON; будущая миграция к SQLite потребует отдельного адаптера/тестов. Не говорить, что SQLite уже встроен.
- Профили памяти пока бюджеты. Их фактическое соблюдение нужно измерять при интеграции worker.
- Никакой загрузки/исполнения произвольных сторонних пакетов.
- GitHub — архив исходников; локальные проверки вместо удалённого CI.
- Название, персонаж и голос пока не утверждены.
