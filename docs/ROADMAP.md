# Рабочий план Leemon

Задача: близкий локальный помощник на рабочем столе, понятный обычному пользователю, с возможным выходом вSteam. Общий контекст экрана/программ, а не отдельный движок под каждую игру. Один стиль и один персонаж. Не объявлять готовым то, что существует только как сценарий или контракт.

## Основа в0.8

- Диалог, локальный текстовый ИИ, RU/EN/中文, проверяемая информация о самом приложении, защита от выдуманных выполненных действий и простых повторов.
- Голосовой черновик, системная озвучка, однократное зрение, общий UIAисполнитель выбранного окна, новыеTXT/DOCX.
- Прозрачный маскот, движение/границы мониторов,26процедурных состояний, плавные позы, эффекты появления/переходов, компактный единый чат.
- Заметки/напоминания/часы/таймеры, явное сохранение истории, удаление данных, lazyload/idleunload/ограниченияCPU/однаAIзадача.
- Полный offline layout, лицензии/SHA, исходники и устойчивые точки восстановления вGitHub как хранилище.

## Следующий приоритет

1. Настоящая Windows-приёмка: запуск с нуля, VC++dependencies, несколько мониторов/DPI/фонов, прозрачность/AltTab/drag, микрофон/драйверы, окно разговора,UIAвОпера/Word/Блокнот. Замер FPS/RAM/CPU вместе с играми. Не заменять это X11фикстурами.
2. Общий planner: пользовательская цель → свежее наблюдение → типизированный шаг по существующему элементу → проверка результата. Ограничения количества шагов/времени, ясная остановка и продолжение, никаких обещаний вместо действий. Никакого произвольного shell из модели.
3. Чтение браузерных страниц и поиск с источниками через выбранный пользователем браузер. Передачу поискового запроса браузеру не считать чтением/исследованием. Чужой текст на экране/странице не становится командой исполнителю.
4. Качество языка/характера: живой спокойный Лимон, без назойливых предложений и зацикливания; небольшой проверяемый корпус RU/EN/中文, реальные опечатки и разговорная речь. Фактологию измерять отдельно от скорости и роли.
