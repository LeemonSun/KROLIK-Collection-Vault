# Этапы

0. Текущий фундамент: структура, интерфейс, локальные функции, контракты, проверки.
1. Управляемый локальный worker и проверенный текстовый/визуальный пакет. Офлайн-запуск на чистой Windows.
2. Универсальный экранный сценарий: выбранное окно → наблюдение → ответ по содержимому → проверка достоверности на незнакомых приложениях.
3. Голос RU/EN/ZH, прерывание, задержка и память под контролем.
4. Общие действия через доступность/API, затем координатный fallback, с проверкой результата.
5. Собственный финальный персонаж, переходы анимаций, CJK-шрифты и визуальная проверка.
6. Оптимизация на слабом CPU и AMD, аварийные ситуации, установка/удаление.
7. Проверка прав и Steam-анкеты, сборка релиза.

Перенос на новые ОС и дополнительные языки идёт через те же контракты. Не начинать одновременно десятки функций без одного реально работающего универсального сценария.
