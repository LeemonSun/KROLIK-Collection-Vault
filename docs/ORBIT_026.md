# Leemon0.26 — implemented Orbit preview

User chose01Orbit on29Oct. The shipping visual system is graphite/amber only. No generated mockup bitmaps, Capri code, extra fonts, new models or third-party UI libraries were adopted.

Changes:
- Shared surfaces/radii/amber actions/dark action text/visible scrollbars and readable conversation hierarchy; larger default chat480x560 with320x280 fallback.
- Four-button open-arc quick menu (conversation/microphone/screen/settings), contextual extras. Still explicitly opened with right-click, not a focus-stealing hover window. Contextual notes/reminders remain reachable internally; only3ordinary settings sections.
- Independent native task/review/observed-choice/result card, driven by a read-only presenter; full proposed field content is scrollable. Approval binds exact current plan JSON+expiry; observed choice binds candidate list. No new effect authority. Cancel/close/repeated same-task/stale drafts tested. Transient task card does not also request incompatible always-on-top flag. Dismiss suppresses subsequent stages until idle. Cancellation never presents an old proposal as a result. Result copies the actual assistant receipt and does not infer business success. Completed card has no repeating countdown. No percentage invented.
- Settings expose real existing installed/download/cancel/checking state and manifest byte totals for conversation, ASR and vision. No model IDs/endpoint/profile/debug/server-start controls in ordinary navigation, even if an old advanced preference exists. OS voice, locale, history, behavior, scale, reduced motion and upstream notices remain accessible. No uninstall UI or custom TTS is claimed.
- Explicit one-utterance voice from Orbit can use a hidden chat editor and submit recognized text without clicking Send. A pre-existing draft never auto-submits; cancel revokes target/auto-send. Microphone remains explicit and20s bounded; no wake-word/continuous listening. Existing shared text worker unloads before ASR as before. System speech is optional and uses installed voices, not a custom character voice.
-30shared-master procedural poses, including4new gestures (adjust_glasses/peek/offer/listen_confirm). Existing texture/6piece rig retained; no hand-drawn hundreds-of-clips claim. Task card presentation uses offer; idle includes glasses/peek; quiet short walks occur only with roam enabled, no open panel/chat/task and no active task/drag/pause/reduced motion. Existing target-window placement remains; no obstacle pathfinding or universal screen agency.
- Existing stage bubbles use factual event labels. Timer greeting is bounded to initial idle startup. No extra inference for UI reactions, no fullscreen blur or perpetual particle system. App frame budget includes visible task card; Windows resource/gameFPS acceptance pending.

Evidence is tracked in session/reports. Initial native regressions exposed outdated test isolation, an invalid on-top+transient combination, and cancellation/dismiss state issues; fixed and new explicit checks added. General native fixtures retain their internal diagnostics test without restoring a user-facing diagnostics tab. The native harness now preserves partial logs on timeout.

Actual Windows/DPI/multimonitor/microphone/voice/real2B acceptance remains pending. The public release gate stays blocked. Friends alpha should first check right-clickOrbit, typing/scrolling, downloads, voice cancel/draft preservation, repeated task cards, native transparency/focus and real machine load. Chibi helper remains late backlog, no assets/runtime introduced.
