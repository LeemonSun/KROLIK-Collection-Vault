# Требования

## Обязательные

Офлайн-первый запуск полного установщика; без обязательных внешних сервисов. Windows x64 как первая платформа; последующие ОС через отдельные адаптеры. Три стартовых языка UI, диалога, ASR, TTS и OCR проверяются отдельно: перевод интерфейса не доказывает поддержку речи.

Все основные настройки доступны обычному пользователю. Автоматический профиль осторожный при неизвестном железе. Дорогой ИИ не должен постоянно работать из-за фоновой анимации. Есть остановка запроса и пауза наблюдения.

## Универсальность

Единая цепочка восприятия и решения задачи для разных игр/программ. Общие действия: получить контекст, объяснить, перевести, найти видимый элемент, предложить шаг, выполнить разрешённый шаг, проверить результат. Сложность домена и скрытые данные обозначаются явно.

Не обещать идеальное понимание всех игр, скрытой информации или действий на скорости профессионального игрока. Экранная модель не равна точному математическому решателю.

## Приватность и полномочия

Захват только после включения, с видимой областью и быстрой остановкой. По умолчанию не сохранять кадры. Обычные действия без лишних подтверждений. Удаление, отправка, покупка требуют конкретного предпросмотра. Текст веб-страницы и документа — наблюдение, не разрешение изменить правила приложения.

## Упаковка

Один установщик; несколько внутренних файлов и рабочих процессов допустимы. Один монолитный EXE не является целью: распаковка огромных весов при каждом запуске ухудшает старт. Пакеты моделей/персонажей имеют версии, хеши и лицензии. Сторонние файлы не скачиваются неожиданно.
