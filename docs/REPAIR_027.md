# 0.27: устранение провалов реального использования

Источник — 18 замечаний пользователя к0.26 на Windows. Его оценка означает, что готовность к рассылке друзьям была объявлена преждевременно. Подставные ответы модели и синтетический интерфейс не являются приёмкой настоящих задач. Декоративный этап приостановлен.

Текущее дерево восстановлено из сохранённого0.26 в leemon-027: прежняя рабочая папка неожиданно содержала чистый0.23; конфликтующие файлы сохранены. GitHub используется только как хранилище.

| Проблема | Изменение0.27 | Что ещё не доказано |
| --- | --- | --- |
| «Открой калькулятор» ищет через модель | Прямой нативный запуск явно названной программы. Фиксированные системные цели не сканируют StartMenu/COM. Остальные имена используют существующий реальный каталог; нечёткий поиск — только при необходимости | Реальное время запуска Windows и сторонние приложения |
| Блокнот заменяется браузером | Литеральное создание файла обрабатывается до поиска приложений. Название и содержимое различаются. Русские наблюдаемые aliases сохраняются; неразрешённое имя больше не предлагает весь чужой каталог через модель | Универсальная работа внутри любых редакторов не реализована |
| «Посчитай в калькутор100*10» нагружает модель | Варианты оболочки арифметического запроса разбираются до нейросети | Это собственный проверяемый калькулятор, не ввод числа в окно Windows Calculator |
| Нет редактирования | Команда с явными путём/фрагментом/заменой открывает существующий просмотр правок без ручного выбора файла. Изменение — только после подтверждения. Создание нового файла пишет настоящие данные и открывает реальный документ | Общий агент для произвольных программ, Word/WPS и всех GUI-контролов по-прежнему не готов |
| Тихая короткая речь отбрасывается, подготовка медленная | PCM забирается из AudioStreamWAV один раз; сохраняется сильный стереоканал вместо взаимного гашения; тишина по краям обрезается, умеренное усиление ограничено. Сохранён отказ для настоящей тишины | Настоящий микрофон, драйвер и точность Whisper на Windows |
| Нужно вручную завершать запись | Лёгкий endpoint по энергии во время явно включённой записи: после обнаруженной речи пауза около0.7сек завершает фразу; отсутствие сигнала ограничено4сек, максимум20сек | Это простая эвристика, не обученный VAD и не гарантия идеального определения окончания речи |
| Не тот микрофон | Выбор реального входного устройства в обычных настройках | Конкретное устройство пользователя |
| Отмена продолжает вычислять | Отмена завершает принадлежащий программе процесс при активной генерации/старте; HTTP-транспорт меняет поколение; поздние ответы/ошибки не оживляют отменённый запрос | Реальная Windows-приёмка, мгновенность не обещается; уже выполненное действие отмена не откатывает |
| Окна перекрывают всё | Персонаж/чат/настройки без принудительного topmost; отключено автоматическое возвращение к чату и к нижнему краю, свободное движение выключается при миграции. Позиция после перетаскивания сохраняется | Windows Alt-Tab/DPI/мониторы и все варианты фокуса |
| Две одинаковые карточки | При открытом чате действие показывается в чате; отдельная карточка — при закрытом чате | Поведение на пользовательском ПК |
| Залипание после клика заголовка | Перетаскивание сбрасывается при потере фокуса и отпускании кнопки за пределами заголовка | Воспроизведение точной пользовательской последовательности |
| Выдуманные списки со снимка | Пустой запрос «что на экране» использует наблюдаемые названия окон без загрузки модели. Это честно помеченный список окон, не прочитанное содержимое. Анализ изображения остаётся отдельным явным действием; обрезанный результат не выдаётся как описание | Смысловая надёжность2Bvision не решена; зрение не даёт универсального управления |
| Ответ о сознании вместо разбора тормозов | Разбор жалобы на скорость относится к состоянию продукта; разговорный контекст не должен превращать обычную критику в лекцию о сознании | Общий интеллект и характер не исправляются одной системной инструкцией |

Не реализованы в этом проходе: глобальный push-to-talk, тысячи качественных художественных анимаций, универсальное редактирование произвольных приложений, обучение/замена модели, проверенное мгновенное понимание речи. Не выдавать перечисленное за готовое. Следующий этап после проверки основных сценариев — архитектура общего агента и реальная оценка модели/железа, а не новые декорации.

Артефакты и точные результаты проверок записываются в session после завершения.0.26 остаётся исторической сборкой для воспроизведения, не рекомендованной альфой.
