# Продолжение работы

1. Прочитать PROJECT_STATE.md, README, docs/SCREEN_UNDERSTANDING.md и docs/OPTIMIZATION.md.
2. Сначала прогнать локальные проверки. Не выдавать файл на диске за проверенную сборку Steam.
3. Выбрать реальный универсальный локальный VLM-профиль и один общий сценарий, не отдельный распознаватель каждой игры.
4. При подключении артефактов зафиксировать точную версию, SHA-256, лицензию и обязательные NOTICE.
5. После изменения повторить соответствующие проверки и обновить reports/VALIDATION.md.
6. Сохранять контрольные точки. GitHub — только хранилище; никаких Actions/удалённых заданий.
7. Не откатывать требования пользователя к общему пониманию экрана и автономности.

Пакеты моделей пока отсутствуют. Нет API-ключей и учётных данных. Optional llama HTTP adapter — только разработческая граница, не окончательная защищённая интеграция.
