# Продолжение

Прочитать AGENTS.md, PROJECT_STATE.md, README, docs/SCREEN_UNDERSTANDING.md, docs/SEARCH_AND_INTELLIGENCE.md, characters/signal_01/README.md, production/ART_DIRECTION.md и production/ANIMATION_BRIEF.md.

Работа только локально, GitHub только хранение. Не запускать Actions/деплой/удалённую сборку. Контрольная точка содержит reviewed internal concept art с release_approved=false; это не финально разрешённые Steam-ассеты.

Использовать master_v1 как текущий эталон; лист стилей — предложение, не автоматически новый костюм. Сохранить ростовую фигуру на рабочем столе. Решение о пиксельной технике открыто. Не генерировать все анимации отдельными несогласованными картинками и не выдавать движение цельной PNG за риг. 113 — план событий, 0 готовых клипов.

Поиск сейчас только явная передача запроса фиксированному HTTPS поисковику через браузер. Модель не читает страницы, не вызывает инструменты и не выполняет команды ОС. Не менять эти статусы без реальной интеграции. Perception — контракты/буфер, не захват и не VLM.

При подключении модели/голоса/шрифта/клипа: точная версия, SHA-256, лицензия/NOTICE, реальные испытания. Не удалять обязательные уведомления. Локальный inference и интернет-поиск — разные функции; базовая автономность остаётся обязательной.

Проверки: tools/run_checks.py --godot /путь/к/godot; смотреть логи, а не только код выхода. UI smoke без дисплея не доказывает визуальное качество или поддержку китайских глифов. Публичный gate обязан оставаться закрытым, пока отсутствуют доказательства.
