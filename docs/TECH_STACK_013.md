# Leemon: технический выбор для продукта, 28.10.2026

Это исследование и план интеграций, а не перечень установленных возможностей. Проверены официальные документы и репозитории ниже. Отобранный компонент не попадает автоматически в дистрибутив: нужен конкретный релиз, SHA-256, условия всех зависимостей/весов, RU/EN/zh-проверки и измерение на Windows.

## Выбранное направление

Один общий текстово-визуальный worker, стандартные инструменты документов/таблиц/браузера, проверка результата. Отдельная модель на программу не нужна. Предпочитать данные и accessibility API, обращаться к изображению только при необходимости. Модель не выполняет произвольный сгенерированный shell. Сайты, документы и текст экрана — недоверенные данные, не разрешения на действия. Локальная работа не гарантирует ни точность, ни безопасность.

## Что войдёт в нормальную установку Steam

Цель: после «Установить → Запустить» работают все возможности, заявленные для базового продукта. Текущие ручные кнопки загрузки — частная preview-схема. В release base depot должны лежать совместимые runtime, базовые веса, notices и нужные ресурсы. Дополнительные более крупные модели/языковые голоса — только явно обозначенные пакеты, если действительно нужны. Не дублировать весовую модель на каждый язык/приложение; Steam depots поддерживают разделение по OS/language/DLC. Собственный AppID/Steamworks ещё не настроены.

Обновлять код отдельно от стабильных весов, давать откат; данные и настройки остаются вне install directory. Никаких скрытых сетевых ключей или фоновых загрузок. Офлайн не означает, что можно читать новую страницу без интернета. Автозапуск, микрофон, наблюдение окна, история и Cloud должны быть понятными опциями. Удаление истории не удаляет выбранные пользователем рабочие документы.

## Следующие приёмочные задачи

1. Windows-проверка старта/трея/Alt-Tab/DPI, файловых блокировок, обновления, микрофона и UIA на разных версиях Office/WPS/браузера.
2. Измерить процесс+worker в ожидании и работе: RSS, CPU, время первого ответа, tokens/s; сравнить quiet/standard. Потоки не равны фиксированному проценту CPU. Отдельно измерить память ASR+VLM и отсутствие одновременного тяжёлого inference.
3. Сравнить2B/0.8B/4B на одинаковом наборе RU/EN/zh: ошибки в запросах, контекст, отказ от выдуманного действия, планирование, извлечение чисел, экранные задачи. Сохранить реальные ответы, не только keyword PASS.
4. Подключить чтение веб-страниц с URL/временем/выдержками, перенаправлениями и ограничениями размеров; затем bounded планирование. Не выполнять команды, спрятанные в странице.
5. Выбрать конкретный нейроголос и модель OCR. Для каждого сохранить лицензию, происхождение/согласие голоса и тесты всех языков. Только затем распространять файлы.
