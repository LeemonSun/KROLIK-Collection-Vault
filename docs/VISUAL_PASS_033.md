# Визуальный проход 0.3.3

Один стиль по уточнению пользователя: чернильная основа, винный активный слой, серебристый текст, красный сигнал. Цвета и срезы связаны с костюмом героини. Собственные SVG-иконки созданы в коде; чужие UI-картинки, CSS и шрифты не добавлены. Существующие notices и provenance персонажа сохранены.

Референсы принципов компактного desktop UI: https://www.raycast.com/core-features/notes и https://help.nova.app/settings/theme/ . Не переносились их логотипы, ассеты или конкретные экраны.

Изменено: отдельный чат с fixed composer, action deck, широкая/компактная навигация, плавный fade, лёгкий процедурный idle и drag lean. Один стиль, переключения тем нет. Жесты/мимика/лицевой риг и агентный интеллект остаются отдельной работой; этот проход их не имитирует.

Проверки: run_checks PASS; 40 native X11 assertions на готовом PCK и осмотр изображений; 6 PowerShell 7/Linux сценариев реального content update, включая повторный запуск без отката. Windows executable/StatusIndicator ещё не проверены на самой Windows.
