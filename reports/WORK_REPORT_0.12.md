# Leemon 0.12 — обновление и результаты

28 октября 2026. Частная проверочная сборка Windows x64, около 54 МБ. Модели в этот ZIP не включены: папка AI/ от 0.8–0.11 совместима.

## Обновить

1. Закрой Leemon через «Выход». Если завис — заверши Companion.exe в диспетчере задач.
2. Сохрани прежние Companion.exe и Companion.pck в отдельной папке для отката.
3. Из нового ZIP замени оба файла вместе в старой папке приложения.
4. Сохрани папку AI/ и данные AppData. Повторно скачивать полный offline-пакет не нужно.
5. Запусти Companion.exe. Старые START_WINDOWS.cmd/APPLY_FIX не используй.
6. Для отката закрой приложение и верни оба прежних файла.

## Что изменилось

- Единственный персонаж — Лимон. Удалены неиспользуемые изображения, настройки, промпты и актуальные описания прежнего персонажа. Git-история и обязательные лицензии сохранены; восстановление не возвращает удалённые ресурсы.
- До трёх ожидающих сообщений при одном активном ответе. Видна следующая реплика; × очищает только ожидание, ■ останавливает всё. Пауза и ошибка очищают очередь. Команды программ/окно/снимок/микрофон в очередь не попадают.
- Реальные состояния задачи и прошедшие секунды. Реплики загрузки/ожидания/проверки не запускают дополнительную модель. Об успешной записи файла сообщается после проверки результата.
- CSV/TSV: выбор строки/столбца, чтение текущего значения, адресная замена. Повторяющиеся значения в соседних ячейках не мешают.
- DOCX: уникальная замена внутри одного текстового фрагмента с сохранением его оформления и прочих частей пакета.
- XLSX: чтение и изменение существующей ячейки на выбранном по порядку листе. Новое значение записывается как текст, стиль ячейки сохраняется. Книги с формулами отклоняются.
- Предпросмотр → подтверждение → бэкап → запись → проверка. Восстановление тоже требует подтверждения. Внешняя правка блокирует устаревший preview.
- Редактор прокручивается, кнопки подтверждения закреплены. Жесты чтения/ожидания/результата связаны с работой. Плавное завершение ходьбы; на короткие переходы поз повышается лимит кадров, спокойный режим остаётся ограничен. Один графитово-янтарный стиль.

## Как попробовать

Во время обычного ответа отправь ещё сообщение — появится очередь. Для файлов: правая кнопка по Лимону → «Правка файла» либо «редактировать файл». Выбери файл до 1 МиБ. Для CSV/TSV/XLSX задай адрес, нажми «Прочитать выбранную ячейку», введи новое значение справа, затем «Предпросмотр» и «Применить».

Действия в программах и чтение доступного текста браузера по-прежнему идут через выбранное окно/UIA. Это общий механизм, отдельная модель под каждую программу не нужна. Передача поискового запроса браузеру не равна исследованию веба.

## Что проверено

- 25 групп локальных проверок: все PASS, включая source/locale, состояние, HTTP, worker, workflow, память, UI и ожидаемую блокировку публичного релиза.
- 39 проверок очереди и реальных CSV/TSV-транзакций; также пройдены из экспортированного PCK. Планировщик проверялся с подменой модели — это не тест качества нейросети.
- 16 проверок настоящих DOCX/XLSX; также из экспортированного PCK. Независимое повторное открытие через python-docx/openpyxl, проверка форматирования/типов, CRC и байтов всех нетронутых частей.
- 156 проверок нативных окон и рендера на изолированном Linux/X11 из конечного PCK. Редактор, очередь, подтверждение/восстановление, три языка, компактные окна. Это не запуск Windows EXE.
- 9 проверок комплектации конечного PCK: версия, только ресурсы Лимона, настоящие adapter/queue-модули, три локали. Проверен экспортированный запуск.
- 15 Python-проверок восстановления и локальный connector-contract тест: восстановление, сохранение чужих изменений, retirement, source capsule и защита от изменившегося remote head.
- Проверена целостность итогового ZIP. Модели, ключи, пользовательские документы и снимки в Git не добавлялись.

## Что предстоит

- Реальная Windows-приёмка: запуск EXE, DPI/мониторы, NativeFileDialog, file locks/reparse, UIA в реальных программах, микрофон и системный голос. Linux/X11 не заменяет эти проверки.
- Полноценные document/table операции: DOCX между фрагментами, абзацы/вёрстка/колонтитулы; XLSX числовые типы, диапазоны, новые ячейки, формулы/пересчёт/диаграммы. Текущие адаптеры имеют узкие границы; это ещё не замена Word/Excel.
- Общие browser workflows и модельные планы с ограничением шагов и проверкой результата. Сейчас нет произвольного автопилота любой программы.
- Более сильный offline-интеллект на измеренном железе. Качество 2B-модели на настоящем inference в этом проходе заново не оценивалось; фактические ошибки возможны.
- Steam Cloud, собственный голос, художественные клипы/липсинк и clearance публичного релиза. Текущие 26 состояний процедурные, из одного мастера.

Лимиты: файл до 1 МиБ; OOXML до 256 частей/8 МиБ после распаковки/2 МиБ на часть; без макросов/подписанных пакетов; CSV/TSV до 10 000 строк, 256 столбцов и 50 000 ячеек. Одна тяжёлая AI-задача, ограничение CPU/контекста, RAM headroom и idle unload сохранены; строгого ограничения RSS средствами ОС нет.
