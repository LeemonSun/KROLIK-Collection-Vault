# Отчёт прохода 0.5.0 · 27.10.2026

Результат: подготовлена и сохранена частная Windows x64 сборка Leemon 0.5.0. Это следующий рабочий preview, не готовый Steam-релиз.

## Сделано

1. Перевёл активного персонажа на нового лимона в очках/костюме. Один прозрачный мастер, шесть согласованных деталей 2D-рига, восемь процедурных состояний. Подключены реакции на запрос, ответ, успех, ошибку, захват и ходьбу. Старые ресурсы девушки сохранены как архив и не входят в экспорт.
2. Собрал один графитово-янтарный стиль: панели, чат, меню действий, иконки и оформление приложения. Исправил навигацию в коротких широких окнах и обновление страницы напоминаний после команд из чата.
3. Добавил офлайн-часы с 597 зонами/2039 алиасами; сохраняемые напоминания с отменой/повторным запуском; явный перевод буфера только собственным локальным worker, без сохранения исходника в истории. Отдельные подсказки для неоднозначного/отсутствующего города, просроченных данных и неподготовленной модели.
4. Ограничил потоки AI по числу процессоров: половина логических, минимум один, максимум восемь. Риг использует одну общую текстуру, не нейросетевую генерацию кадров. Сохранил ограничение одного тяжёлого задания, выгрузку модели и адаптивный FPS. Это изменения политики ресурсов; минимальные требования и выигрыш FPS на слабом Windows-ПК пока не измерены.
5. Сделал двухфайловый updater: восстанавливает EXE с новой иконкой и PCK, проверяет SHA обоих до замены, хранит backup в одной служебной папке, умеет откат, повторный запуск и завершение смешанного old/new состояния. Полный ZIP не содержит россыпи отдельных BAT/CMD/PS1.
6. Восстановил исходники после отключения среды, восстановил проверенные ресурсы, пересобрал чистый пакет, сохранил версию и короткий GIF из фактического рига. Обновлены точка входа, состояние и капсула восстановления: следующему проходу не нужна вся переписка.

## Проверено

- 13 групп checks: structure, core, HTTP, local runtime, search, persistence, Leemon tools, functional, animation, self-knowledge, chat layout, UI, expected release block — PASS. Leemon tools: 47 проверок.
- Собранный PCK в изолированном X11: 76 проверок, 0 ошибок. Включены три языка, ввод, масштабирование, восстановление персонажа, меню, анимационные состояния и напоминания. Покрытие исходного силуэта: потеря 12 из 40392 непрозрачных пикселей в контрольном положении.
- Содержимое PCK и фактический Godot → PowerShell result protocol: 11 проверок PASS. Старый art исключён, новый art/часы/помощник включены.
- Исполнитель PowerShell: 21 проверка PASS; Windows COM не исполнялся.
- Двухфайловое обновление: 8 сценариев PASS, включая повреждение, неизвестную базу, backup, смешанную версию, идемпотентность, откат и ready-ветку стартера.
- GIF: 144 кадра из реально поставляемого рига, 24 кадра/с. Не макет и не независимая генерация изображений.
- ZIP: CRC, SHA-256 и отсутствие внешних BAT/CMD/PS1/весов проверены.

## Ограничения

Нейросеть остаётся Qwen3-1.7B Q8_0, не новым авторским обучением. Параметры разговора/перевода настроены, короткие RU/EN/zh переводы ранее проверены на реальном CPU worker, но научный ответ при ручной оценке оказался неточным. Тесты маршрутизации и самоописания не гарантируют общую правдивость ответов.

Это восемь базовых процедурных движений cutout, не тысячи художественных клипов, не полноценная мимика и не 3D. Нет ASR/собственного голоса, анализа экрана, самостоятельного исследования веб-страниц. Веса около 1,86 ГБ пока скачиваются отдельной установкой. Steam Cloud не подключён.

Настоящая Windows здесь недоступна; запуск EXE, прозрачность, COM, голоса, установщик модели и блокировки файлов требуют теста на пользовательском ПК. Точная производительность слабых ПК не заявлена. Коммерческий выпуск остаётся заблокирован до приёмки.

Часть времени ушла на восстановление после отключения среды и проверку упаковки/отката. Количественную разбивку по минутам не вёл; весь прошедший час нельзя честно назвать только разработкой функций.
