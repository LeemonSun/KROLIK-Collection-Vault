# Вложенные runtime

В этой версии нет бинарников worker. Будущий установщик размещает проверенные платформенные executables/libraries здесь. Приложение управляет запуском и остановкой, не требует отдельной установки Python/Ollama.

Запрещены неожиданные сетевые загрузки, shell-строки из ответа модели, фоновые службы без необходимости. Платформенные аргументы передавать массивом, с отдельными путями. Нужны контроль процесса, handshake/токен или local pipe, таймаут запуска, отмена, проверка хеша и очистка при выходе.

Текущий фиксированный loopback HTTP-адаптер — инструмент разработчика; доверенная идентификация реального worker ещё не реализована.
