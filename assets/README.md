# Материалы

`foundation.svg` и процедурный персонаж из `src/ui/companion.gd` созданы для этого каркаса. Это временный нейтральный образ, не финальный персонаж и не копия Capri.

Папки будущих материалов: `characters/`, `audio/`, `fonts/`. В текущей поставке финальных материалов нет. Каждому внешнему файлу нужны источник, лицензия, SHA-256 и статус проверки. CJK-шрифт пока не вложен, поэтому наличие китайских глифов зависит от окружения; это блокер публичного выпуска.
