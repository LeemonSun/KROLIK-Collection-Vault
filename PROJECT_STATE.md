# Состояние проекта

Исходники 0.4.0-functional-preview; последняя выданная до этого прохода сборка 0.3.3-visual-preview, 27.10.2026. Частная Windows preview, не Steam release.

## Решения

Самостоятельное приложение для Steam, локальная база без обязательного облака/ключей. RU/EN/zh-Hans. Экономная работа на слабом ПК, минимум нужно измерить. Общий контекст задач и экрана; не отдельный движок под каждую игру. Оптимизация модулей, проверка изменений весов по baseline. GitHub только хранит код/материалы/готовую preview, без Actions и удалённых сборок.

Обсуждается лимон-маскот в очках и костюме (новый концепт, не animation sheet). В этом функциональном патче текущая героиня 01 остаётся. Пиксельный вариант **отложен по указанию пользователя**. Образ в полный рост поверх рабочего стола без рамки; серебристый объёмный хвост, винно-молочная форма, отдельный красный сигнал. Не копировать Capri/чужие персонажи, код, анимации или голос. Имя/голос/бренд рабочие.

## Реализовано

Семь страниц Godot; заметки/таймеры/пауза/отмена; встроенный CJK-шрифт. Native-window персонажа: прозрачность, перетаскивание, красный переход, редкое добровольное перемещение, уменьшенные эффекты. Это window/FX prototype со статичным cutout, не риг/лицевая анимация.

Установщик локального Qwen3-1.7B Q8_0 + llama.cpp b11901, закреплённые версии/SHA, явная загрузка по кнопке, owned CPU-worker/токен/случайный loopback, очередь первого вопроса, контекстный бюджет, один слот, выгрузка и остановка. Текстовый реальный inference проверен на Linux, Windows worker пока нет.

Системная озвучка ответов доступными голосами ОС; разовый снимок экрана только в память окна просмотра; кнопка поиска передаёт запрос браузеру. Страницы и снимок не анализируются моделью. Есть директор с 113 запланированными событиями, готовых body clips 0. Рабочие материалы/происхождение сохранены; создан Windows PE EXE, упаковка выполняется локально.

## Не готово

Качественный единый риг/клипы/мимика/губы, собственный голос, VLM-экранное понимание, чтение сайтов и исследование, длинная семантическая память, самостоятельные действия в чужих программах, полноценный установщик/обновления, Steam SDK/магазин. На настоящей Windows не проверены запуск/прозрачность/загрузка/голос/снимок/DPI. Правовой допуск публичного контента не завершён.

## Следующий этап

Проверка EXE пользователем, исправление Windows-конкретных проблем; настоящее производство первых выразительных движений из одного исходника; сравнение более сильного общего VLM-пакета и один реальный сценарий по выбранному окну. Не называть статичную картинку ригом, каталог клипами, разовый текстовый тест общим интеллектом, локальную сборку проверенным Windows-релизом.

## Исправление после первого теста

Пользователь сообщил, что поле ввода/нижний текст недоступны и не принимает постоянно открытую панель как образ продукта. Добавлены компактный ChatView с фиксированным composer, отдельное окно чата, startup с персонажем, короткое меню и скрываемая панель настроек со скроллом. В 0.3.1 применялся offscreen 1px host; в 0.3.2 эта схема удалена после сообщения о недоступном приложении. На X11/llvmpipe реально проверены startup, поля, прокрутка и показ/скрытие. Это не Windows-проверка.

Добавлены Opera/GX preference для URL handoff и защита stop при недоступном TTS. Пиксели по-прежнему отложены. Текстура только получила mipmaps; качество оригинальной графики и rig этим не решены. Последние продуктовые требования подробно в docs/PRODUCT_DIRECTION.md.

Доставка: Companion.exe + Companion.pck. Патч к оригинальной 0.3 строит точный новый EXE из исходных байтов и 128 KiB литералов, проверяет хеши, сохраняет backup и переносит новый PCK. Модель/профиль отдельно и не изменяются. Полная preview и ресурсный pack проверены локально; публичный gate закрыт.

## 0.3.2: доступный запуск

Главное окно теперь рисует персонажа и остаётся доступным через панель задач. Hide сворачивает его; recover возвращает на основной экран и сбрасывает нулевую alpha. Windows/macOS StatusIndicator возвращает персонажа/чат или настройки. При недоступном арте появляется recovery panel. UI больше не исключён из обычных скриншотов. 29 native X11 проверок готового пакета, 6 PowerShell-сценариев патча/launcher; Windows ещё не выполнена.

Пользователь уточнил: сейчас делать один тщательно проработанный стиль; переключение тем не нужно. Сначала устранить блокирующий запуск, затем продолжить большой визуальный проход.

## 0.3.3: единый визуальный слой

Одна винно-серебристая тема и авторские SVG-иконки, рисованные поверхности со срезами, новый компактный чат с подсказками, собственное меню из шести действий, широкая боковая навигация и компактный dropdown; черновик сохраняется при смене размера. Мягкое появление/закрытие чата. В cutout добавлена процедурная деформация волос/дыхания и наклон при переносе; это не риг и не готовые body clips. Пауза и reduced motion отключают движение; исправлено возобновление после паузы. 40 проверок готового PCK на X11, 6 сценариев обновления.

Sandbox download links у пользователя недоступны. Полный ZIP отправлен как самостоятельное вложение: libfile_918be8a7635c8191bdb7c7c258f84a8c. Не повторять неработающие sandbox-ссылки для архивов.

## 0.3.4-dev — ещё не выпуск

По переписке добавлен SelfKnowledge: точные ответы о состоянии приложения, обычное представление Signal и достоверные технические сведения отдельно. Прочие вопросы остаются у LLM. Персона уточнена; non-thinking sampling согласован с Qwen best practices (https://qwen.readthedocs.io/en/stable/getting_started/quickstart.html), payload проверен HTTP fixture. Длинный ответ по явному запросу получает до 192–256 токенов; обычный lite-бюджет сохранён. Новая речь на настоящем local worker ещё не оценена: GGUF в среде отсутствует.

Добавлен пересчёт окна/маски при смене usable rect и уменьшении монитора; проверены уменьшенные и отрицательные координаты. Собирать следующий выпуск общим пакетом после замечаний к 0.3.3, не отправлять мелкий патч на каждую реплику. Статус 0.3.3 и ранее выданное вложение не менять задним числом.
