# Состояние проекта

Версия 0.2.0-character-foundation, 27.10.2026.

## Закреплённые решения

Самостоятельное приложение для будущего Steam, локальные базовые функции без обязательных облака/ключей; установщик должен включать компоненты. RU/EN/zh-Hans с последующим расширением. Экономная работа на слабом ПК; точный минимум не измерен. Общий контекст экрана и задач, а не обязательный движок под каждую игру. Модули исключать, pruning весов проверять экспериментально по трём языкам и общим задачам. GitHub исключительно хранит исходники и checkpoint, без удалённых работ/Actions.

Выбран концепт 01: девушка как живая программа ПК, объёмные светлые волосы с винной подложкой, отдельный красный след/быстрые перемещения. Не копировать Capri, её персонажа, интерфейс, голос или ассеты. Основной вид — **в полный рост без рамки на рабочем столе**; крупные лица только вспомогательные эталоны. Пиксельный/гибридный стиль рассматривается, не утверждён. Не скрывать AI-происхождение сменой техники. Имя/голос/бренд открыты.

## Фактически готово

Шесть страниц Godot, локализация, локальные заметки/таймеры, отмена/пауза, loopback-адаптер (по умолчанию выключен); кнопка и команды явного поиска в браузере. Буфер наблюдений и контракты; код директора движений с каталогом 113 **планируемых** событий и 0 клипов. Папка characters/signal_01 содержит шесть изображений, дизайн/происхождение и постановочные материалы. OPEN_PREVIEW.html позволяет посмотреть материалы без Godot.

## Пока отсутствует

Нейросетевые веса/управляемый worker, реальное понимание страниц и экрана, голос, риг/готовые клипы, прозрачное desktop-окно, произвольная автоматизация, Steam SDK, Windows EXE/установщик. HTML-просмотр — просмотр материалов, не действующий интеллектуальный агент. Результаты поиска приложение не читает. Тесты клипов используют искусственный ресурс, не художественную анимацию.

## Дальше

Не раздувать интерфейс заглушками. Выбрать технику после небольшого настоящего motion-прототипа; собрать один согласованный риг/набор исходников. Параллельно следующий инженерный этап — локальный worker и общий сценарий: выбранное окно/страница → локальная модель → ответ по содержимому со ссылкой/неопределённостью. Никаких обещаний нулевого юридического риска, «лучше Capri» и измеренной работы на любом ПК без реальной проверки.
