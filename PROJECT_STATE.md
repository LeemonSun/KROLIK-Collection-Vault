# Состояние проекта

Версия: 0.1.0-foundation. Дата: 26.10.2026.

## Решения пользователя

- Самостоятельная программа для будущего выпуска в Steam.
- Базовые функции полностью на ПК пользователя, без обязательного облака и API-ключей.
- Пользовательский установщик включает необходимые компоненты.
- Стартовые языки: русский, английский, китайский; расширяемые пакеты.
- Важны красивый дизайн и работа на слабом ПК.
- Нужен общий контекст экрана, не набор отдельных систем под каждую игру.
- Шахматы — один пример из множества; отдельный движок не основа продукта.
- Оптимизировать, исключать неиспользуемые модули. Изменять веса модели только после проверки, не обещать удаление «навыков» без потерь.
- GitHub использовать исключительно как хранилище, без выполнения работ и сборок на нём.
- Итоговое название, персонаж и голос пока не выбраны.

## Реализовано

См. README. Реальные функции сейчас: интерфейс, заметки, таймеры, локализация, настройки, пауза/отмена, необязательный loopback HTTP-адаптер. Perception — универсальный буфер и контракты, но не захват экрана и не визуальная модель.

## Не делать при продолжении

Не выдавать за подключённое то, что остаётся заглушкой. Не подменять универсальное понимание классификатором игр. Не выполнять произвольные команды ОС из ответа модели. Не добавлять телеметрию или облако по умолчанию. Не запускать GitHub Actions. Не превращать обещания качества, задержки и отсутствия юридического риска в якобы проверенные факты.

## Следующий этап

Один реальный вертикальный сценарий: пользователь выбирает окно → локальное наблюдение → единая визуальная модель описывает увиденное → ответ с явной неопределённостью. После этого — измерения и обобщение на незнакомые программы. Не добавлять десятки отдельных распознавателей вместо этого.
