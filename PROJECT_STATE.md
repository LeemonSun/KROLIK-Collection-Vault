# Leemon — состояние 0.12

Единственный персонаж — Лимон, один графитово-янтарный стиль. Источник истины для продолжения — RESUME.md и recovery/session.json; детали последнего блока — docs/WORKFLOWS_012.md.

Есть: общий локальный текстовый worker, однократный screen context, Windows UIA selected-window действия и чтение с источниками, ограниченные пользовательские цепочки; одна тяжёлая задача, явная компактная память; 26 процедурных поз из одного мастера. В0.12 добавлены очередь обычных сообщений, реальные события прогресса, адресные CSV/TSV и ограниченные DOCX/XLSX с preview/backup/verification. Новые UI и работа с файлами проверяются локально и в экспортированном PCK.

Нет: проверки текущей Windows-сборки на настоящем ПК, универсального автопилота, полноценной замены Office, произвольных browser workflows, SteamCloud, доказанной универсальной точности 2Bмодели и clearance публичного релиза. Все ограничения и число проверок — session. Старые release artifacts сохранены отдельно, не являются текущими исходниками.
