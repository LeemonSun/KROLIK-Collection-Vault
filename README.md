# Leemon 0.12 — локальный помощник

[Сборка Windows x64, 54 МБ](https://chatgpt.com/library?file_id=libfile_59fd4fb8f5ac81919d46809a2044f85f&account_id=personal) · [Обновление, проверки и ограничения](https://chatgpt.com/library?file_id=libfile_5a9a8d0e9a248191aef85a9968b11518&account_id=personal)

Закрой Leemon, сохрани прежние EXE/PCK для отката, замени оба файла вместе. Папку **AI/** и данные AppData сохрани: модели 0.8–0.11 совместимы. Новый ZIP включает подробную инструкцию; полный offline-пакет повторно скачивать не нужно. Исторический START_WINDOWS.cmd не является установщиком актуальной версии.

Единственный персонаж — **Лимон**, один графитово-янтарный стиль. 26 процедурных поз из одного мастера. Новое: очередь до трёх обычных сообщений при одном активном ответе, отмена ожидания, события прогресса без дополнительной модели, адресные CSV/TSV, ограниченные настоящие DOCX/XLSX с предпросмотром/подтверждением/бэкапом/проверкой. Редактор прокручивается, кнопки закреплены; file-state жесты и плавное окончание ходьбы.

Общий механизм выбранного окна/UIA, одноразовое чтение с источниками, снимок по запросу и локальный worker сохранены. Одна тяжёлая AI-задача, CPU/context limits, RAM headroom, lazy load и idle unload. Отдельной модели под каждую программу нет. RU/EN/zh-Hans.

25 групп локальных проверок PASS. Из конечного PCK:156проверок nativeX11,39queue/CSV/TSV,16Office+независимое открытие,9комплектации. ZIPCRC проверен. **Windows EXE/UIA/DPI/блокировки файлов/микрофон/системный голос здесь не испытаны.** DOCX — одна замена в одном текстовом фрагменте; XLSX — существующая ячейка как текст, книги с формулами отклоняются. Это частная preview, не законченная замена Office/браузера, не универсальный автопилот и не Steam-релиз. Качество реальной2Bмодели в этом проходе не переоценивалось.

Продолжение: [RESUME.md](RESUME.md), recovery/session.json, [описание 0.12](docs/WORKFLOWS_012.md). Сохранённые исходники и артефакты0.11 перечислены в session. GitHub только хранит файлы: без Actions/remote builds/deployment. История и обязательные лицензии сохранены; удалённые концепты не восстанавливать. Модели/ключи/пользовательские файлы/снимки не коммитить.
