# Companion Foundation

Основа автономного персонального ИИ-компаньона для Steam. Рабочее название, финальный бренд не выбран.

Цель: единое понимание экрана и задачи пользователя в играх, браузере и программах. Архитектура не строится на отдельном движке для каждой игры. Визуальная модель, текст интерфейса, история наблюдений и доступные инструменты образуют общий контекст. Специализированные инструменты — возможное дополнение.

## Что уже есть

- Запускаемая оболочка Godot: разговор, заметки, модули, настройки.
- Русский, английский, упрощённый китайский: 77 общих ключей интерфейса.
- Локальные заметки с атомарной записью, таймеры, отмена запроса, пауза.
- Профили мощности и выбор по общей памяти компьютера.
- Ограниченный адаптер llama.cpp по loopback, выключенный по умолчанию.
- Универсальный буфер наблюдений, договорённости между модулями, ограничение тяжёлых заданий.
- Реестр кандидатов моделей и лицензий, блокировка неподготовленного публичного выпуска.
- Тесты логики, HTTP-адаптера и проход по всем страницам и языкам.

## Что пока не работает

Нет встроенных весов ИИ, управляемого процесса llama.cpp, голоса, захвата экрана, настоящего визуального понимания, управления чужими программами, интеграции Steam, окончательных персонажей и установщика. Интерфейс честно сообщает об отсутствии модели. Это исходники фундамента, не готовый пользовательский EXE.

## Запуск для разработки

Требуется стандартный Godot 4.7.2, без .NET. Открыть project.godot и нажать F6/F5 (главная сцена — scenes/main.tscn). Либо:

    godot --path .

Пользователь будущего установщика не должен устанавливать Godot или Python. Python используется только для инструментов разработки и упаковки.

Проверки:

    python tools/verify_project.py
    godot --headless --path . --script res://tests/test_core.gd -- --test-mode
    python tools/test_http.py /path/to/godot
    godot --headless --path . -- --ui-smoke --test-mode

Команды в разговоре: /timer 30, /note текст, /notes, /help. Есть русские и китайские псевдонимы. Все числа таймеров — секунды; таймеры действуют, пока работает программа.

## GitHub

Только хранилище исходников и контрольных точек. Разработка и проверки выполняются локально. GitHub Actions, CI-запуски, удалённая сборка и задания не настроены. Не публиковать ключи, пользовательские данные, личные снимки экрана и непроверенные материалы.

## Права

Собственный код и исходная временная графика относятся к проекту. У сторонних движков, моделей и материалов свои условия. См. legal/README.md и manifests/components.json. Обязательные уведомления сохраняются; происхождение моделей не скрывается. Реестр кандидатов не является утверждением, что они уже вложены или полностью проверены.
