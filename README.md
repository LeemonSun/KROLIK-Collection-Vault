## Оконные цели0.9

Выбери программу и напиши «переключись на вкладку Вставка». Локальная модель предлагает один шаг по доступным элементам. Кнопка подтверждения называет действие; перед исполнением окно читается заново, выбор/раскрытие проверяются по состоянию. Для обычной кнопки нужно явно попросить нажатие и назвать её. Это не многошаговый автопилот.

Обновление0.9 распаковывается поверх полного0.8комплекта. **ПапкуAI сохраняй:** модели не менялись. Полный комплект ниже по-прежнему0.8; после его распаковки скопируй поверх приложение0.9 по верхней ссылке.

## В этой версии

Локальный Qwen3.5-2B Q4, разовый анализ экрана, голосовой ввод Whisper в черновик, выбор внешнего окна и общие UI Automation действия по доступным элементам. TXT/DOCX создаются новыми файлами в Documents/Leemon. Заметки, таймеры, часовые пояса, напоминания и запуск приложений работают без модели.

Компактный Лимон210×232, размеры75–150%,16 процедурных состояний из одного рисунка и плавное смешивание поз. Карточки диалога с копированием, один графитово-янтарный стиль,6 основных страниц, служебные инструменты скрыты.

Полный offline layout поддерживается: **AI/text**, **AI/voice**, **AI/vision** рядом с EXE. Первый запуск проверяет файлы в фоне, не копирует модели и не загружает их в память. Лёгкий пакет54 МБ предлагает установить модели кнопками из чата. Модели никогда не хранятся в Git.
