# Leemon 0.13 — локальный помощник

[Windows x64, 54 МБ](https://chatgpt.com/library?file_id=libfile_909ecf9b0d7881918b99c6d5bdc30516&account_id=personal) · [Отчёт и исследование компонентов](https://chatgpt.com/library?file_id=libfile_41c9575efca0819192fb7b4b3718ab99&account_id=personal)

Закрой программу, сохрани прежние EXE/PCK для отката и замени оба файла вместе. **AI/ и AppData сохранить:** модели 0.8–0.12 совместимы. Новых весов в 0.13 нет. START_WINDOWS/APPLY_FIX — исторические файлы, не текущий установщик.

Единственный персонаж — Лимон. Один графитово-янтарный стиль, 26 процедурных поз из одного мастера. Технические изменения 0.13:

- Экономный режим по умолчанию: один поток, batch32, выгрузка после 30 секунд простоя; предел применяется и к ASR. Это мягкий бюджет, не строгая квота CPU/RAM.
- Замена текста в обычном абзаце DOCX через соседние фрагменты форматирования.
- Явные типы существующей ячейки XLSX: текст, число, Boolean. Формулы не пересчитываются; книги с формулами и защищённые структуры отклоняются.
- Сводка диапазона до 1024 ячеек без модели и записи файла. Приближённая double-арифметика, исходные числа без интерпретации дат/процентов.
- Закреплённые предпросмотр и результат. Проверки, подтверждения, резервные копии и откат сохранены.

26 групп проверок исходников прошли. Из финального PCK: 9 проверок состава, 44 технические, 33 Office с независимым чтением, 156 общих и 34 новых нативных проверки окон; CRC ZIP проверен. Испытания выполнены в Linux/X11. **Windows EXE/UIA/DPI, блокировки файлов, native picker, микрофон и TTS требуют настоящей Windows-приёмки.** Качество модели и её реальная производительность в 0.13 не переизмерялись.

Это частная preview, не универсальный автопилот, не полная замена Office/браузера и не готовый Steam-релиз. Steam Cloud не подключён.

Продолжение: [RESUME.md](RESUME.md), recovery/session.json, [изменения 0.13](docs/WORKFLOWS_013.md), [выбор компонентов](docs/TECH_STACK_013.md). Кандидаты из исследования не установлены. GitHub только хранит исходники: без Actions, remote builds и deployment. История, retirement guards и обязательные лицензии сохранены. Веса, ключи и пользовательские файлы не коммитить.
