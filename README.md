# Leemon 0.14 — основа общего помощника

[Windows x64, 54 МБ](https://chatgpt.com/library?file_id=libfile_1f130b15d4b481919b3a2baab377add7&account_id=personal) · [Отчёт, копилка компонентов и план](https://chatgpt.com/library?file_id=libfile_76dfcb96f9148191932f3304c5f5f8a2&account_id=personal)

**Главная цель — общий адаптивный агент:** наблюдать UI/экран, понимать свободную задачу, строить ограниченный план, пользоваться инструментами в уже установленных программах, повторно наблюдать и проверять результат. Каталог ручных команд — поддержка, не замена интеллекта. Отдельная модель под каждую программу и своя замена Office/виртуальная среда не нужны. Такой универсальный контур пока не завершён; это главный следующий этап.

В 0.14 добавлены калькулятор, перевод единиц, фиксированные переходы к настройкам Windows и ограниченный читатель явно указанной публичной HTTPS-страницы. Расчёты/единицы/статусы/извлечение текста не запускают LLM. Сохранены инструменты документов, selected-window UIA, 26 процедурных состояний Лимона, экономный бюджет и один тяжёлый worker. Новых моделей нет. В копилке 21 компонент с ролью, лицензией и условиями интеграции; кандидаты не установлены автоматически.

Обновление: закрой программу, сохрани старые EXE/PCK для отката и замени оба файла вместе. **AI/ и AppData сохранить:** модели 0.8–0.13 совместимы. START_WINDOWS/APPLY_FIX — исторические файлы, не текущий установщик.

29 групп исходников прошли. Финальный PCK: 9 проверок состава, 112 utilities, 16 сетевой машины состояния, 7 настоящего локального TLS с независимым сервером, 33 Office с независимым чтением, 215 нативных X11-проверок. CRC ZIP проверен. Внешний DNS в рабочей среде недоступен: **успешный доступ к публичным сайтам здесь не подтверждён**. Windows EXE/UIA/DPI/блокировки/микрофон/TTS также требуют настоящей приёмки. Это private preview, не готовый Steam-релиз и не полная замена Office/браузера. Cloud не подключён. Качество 2B и реальная производительность не переизмерялись.

Продолжение: [RESUME.md](RESUME.md), recovery/session.json, [изменения и главный план](docs/WORKFLOWS_014.md), [исследование стека](docs/TECH_STACK_013.md), research/component_backlog.json. GitHub только хранит исходники: без Actions/remote builds/deployment. Сохранять историю и лицензии; не возвращать retired characters; не коммитить веса, ключи и файлы пользователя.
