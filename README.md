# Leemon Companion · 0.5.0 preview

[**Скачать готовую Windows x64 сборку · 51 МиБ**](https://chatgpt.com/library?file_id=libfile_aa492c7431c88191a105c25f22539735&account_id=personal)

Распаковать целиком в пустую папку и запустить **Companion.exe**. Модель и профиль предыдущей версии сохраняются в AppData. В полном ZIP нет отдельных BAT/CMD-установщиков. Это частная тестовая сборка будущего компаньона для Steam.

## Что есть сейчас

- Новый лимон Leemon в очках и костюме; один графитово-янтарный интерфейс. Персонаж — главное окно без рамки. Клик открывает чат, ПКМ — действия, перетаскивание — перенос.
- Один мастер 1199×1312, шесть частей 2D-рига, восемь процедурных состояний: покой, приветствие, размышление, речь, успех, заминка, захват и ходьба. Детальная мимика и законченные рисованные клипы пока отсутствуют.
- RU/EN/zh-Hans, адаптивные панели и ввод, заметки, таймеры, опциональная история до 100 сообщений/256 КиБ, удаление истории и заметок.
- Офлайн-часы: 597 IANA-зон и 2039 локализованных имён/алиасов. Это каталог зон, не всех городов мира. Данные IANA 2026e/CLDR release-48, период 2020–2036, уведомление при неоднозначности/неподдерживаемом городе.
- Напоминания сохраняются после закрытия: до 32, горизонт 31 день. При закрытой программе уведомление появится при следующем запуске.
- Перевод буфера только по явной команде и только своим локальным worker. Исходник не помещается в видимую/сохраняемую историю и очищается из очередей после завершения/отмены. Предел 4096 символов и 512 выходных токенов.
- Типизированный запуск установленных приложений/папок с проверяемым результатом отдельного исполнителя. Текст нейросети не подтверждает выполненное действие. Обычный поиск пока передаётся браузеру.
- Один тяжёлый запрос, ограничение AI до половины логических CPU (минимум 1, максимум 8), выгрузка по простою, 60 FPS при активности и 24/30 в покое. Монитор нагрузки приложения и своего worker.

## Быстро проверить

1. `время в Пекине` — без модели и интернета.
2. `напомни через 2 минуты проверить загрузку` — затем посмотреть страницу «Напоминания».
3. `открой проводник` — результат должен прийти от исполнителя Windows.
4. `переведи буфер на английский` — после установки модели.

**ИИ пока загружается отдельно** в «ИИ и инструменты»: закреплённый llama.cpp b11901 и Qwen3-1.7B Q8_0, около 1,86 ГБ при первой установке, далее локальная работа без облака. Веса не переобучены и не выдаются за собственную модель; общее качество ответов ограничено, в том числе по научным вопросам. Системные голоса зависят от Windows. ASR, собственный голос, универсальное понимание экрана и самостоятельное чтение страниц не готовы.

## Обновление и сохранность

Подготовлено проверяемое двухфайловое обновление EXE+PCK 0.4 → 0.5, около 1,3 МБ, с SHA-256, резервными копиями и откатом. Оно сохранено в downloads вместе с manifest. Для обычного теста проще полный ZIP выше. GitHub используется **только как хранилище**; Actions и удалённые сборки не используются.

При скачивании исходников из GitHub корневой START_WINDOWS.cmd собирает сохранённые пакеты и применяет обновления локально. Готовая ветка запуска 0.5 и обновление 0.4 проверены; вся историческая цепочка 0.3 → 0.5 в этом проходе повторно не проверялась.

## Проверки и разработка

13 групп основных проверок PASS; 76 native X11 UI-проверок; 11 проверок содержимого экспортированного PCK и фактического Godot → PowerShell roundtrip; 21 проверка исполнителя; 8 сценариев двухфайлового обновления. Windows EXE на настоящей Windows здесь не запускался — требуется приёмка прозрачности, перетаскивания, установщика, системного голоса и блокировок файлов. Протоколы и UI проверены на Linux, это не замена Windows-тесту.

Быстрый вход: [RESUME.md](RESUME.md), затем `python3 tools/resume.py status`. Источники восстанавливаются капсулой с хешами и сохранением неизвестных локальных правок. [Отчёт прохода](reports/WORK_REPORT_0.5.md), [журналы проверок](reports/VALIDATION.md), [изменения](CHANGELOG.md).

Godot 4.7.2 standard. Проверки: `python3 tools/run_checks.py --godot /path/to/godot`. Локальная упаковка: tools/build_preview.py. Пользовательские файлы, веса, ключи и снимки экрана в Git не сохраняются.

Лимон — внутренний AI-концепт; исключительные права и готовность коммерческого выпуска не заявлены. Public release gate остаётся закрыт до художественной, технической и лицензионной приёмки.
