# Companion Foundation · 0.2

Основа локального ИИ-компаньона для будущего выпуска в Steam. Рабочее название. Основной образ — героиня в полный рост поверх рабочего стола без рамки; текущее окно Godot — инженерный прототип, а не финальный вид.

[**Скачать весь проект одним нажатием (ZIP)**](https://github.com/LeemonSun/KROLIK-Collection-Vault/archive/refs/heads/main.zip)

Приватный репозиторий: для скачивания нужно войти в GitHub с доступом. ZIP содержит материалы и исходники; Windows EXE пока не собран.

## Сначала посмотреть

Распаковать ZIP и открыть **OPEN_PREVIEW.html** обычным двойным щелчком. Без установки Godot, сервера и моделей: ростовой рабочий образ, все листы, сравнение стилей, план движений и явный поиск в браузере. Это локальный просмотр материалов, не действующий интеллектуальный агент и не готовая анимация.

## Что готово

- Godot: шесть страниц, RU/EN/zh-Hans, заметки, таймеры, пауза и отмена.
- Явный поиск: /search, /поиск, /搜索 или кнопка; запрос передаётся DuckDuckGo через браузер по умолчанию. Интернет нужен для результатов.
- Рабочая героиня 01, шесть изображений с происхождением/хешами, черновики ракурсов/эмоций/красного перемещения и проба пиксельной техники.
- Код директора движений: слои, приоритеты, прерывания, ограничения и проверка пакета. **113 запланированных событий, 0 готовых клипов.**
- Ограниченный loopback llama HTTP adapter, выключенный по умолчанию; общий буфер наблюдений, контракты модулей и проверки.

## Что ещё предстоит

Встроенная модель/worker, самостоятельное чтение страниц, общее понимание экрана, голос, долговременная память, риг/клипы, прозрачное desktop-окно, управление чужими приложениями, Steam SDK, установщик и проверка на Windows. Поиск браузером не означает прочитанные результаты. Недостающие возможности не подменяются заготовленными «умными» ответами.

## Запуск Godot

Стандартный Godot 4.7.2 без .NET: открыть project.godot и F5. Для разработчиков, не требование будущему пользователю. Команды: /help, /note текст, /notes, /timer 30, /search запрос; есть RU/ZH псевдонимы. Таймеры работают, пока запущено приложение.

    python tools/run_checks.py --godot /path/to/godot
    python tools/package_source.py --output ../Companion_Foundation_v0.2_Source.zip
