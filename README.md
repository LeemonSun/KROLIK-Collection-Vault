# Companion Preview · 0.3

Локальный ИИ-компаньон для ПК, частная тестовая версия будущего продукта для Steam. Пиксельное направление отложено; продолжаем текущую героиню Signal 01, имя рабочее.

Репозиторий приватный: войти в GitHub с доступом. Готовая версия хранится частями в downloads; START_WINDOWS.cmd восстанавливает её локально. Раздел Releases не создан: доступное GitHub-подключение не поддерживает его запись. GitHub используется только для хранения; сборка и проверки выполнены локально.

## Быстро запустить

1. Скачать ZIP по кнопке выше, полностью распаковать и открыть **START_WINDOWS.cmd**. Он проверит и восстановит готовый пакет из downloads, распакует его и запустит Companion.exe. Это сборка из сохранённых частей, без компиляции, сети и установки инструментов разработки. Дальше EXE находится в build/windows-preview/Companion_Preview. Отдельный обычный Windows ZIP можно скачать из ответа в чате; в нём сразу открыть Companion.exe.
2. Появятся окно приложения и ростовой персонаж на рабочем столе. ЛКМ — перетащить, ПКМ — красный переход, двойной клик — основное окно, средняя кнопка — скрыть. Вернуть: «На рабочий стол».
3. Для чата открыть **«ИИ и инструменты» → «Скачать и установить локальный ИИ»**. Один раз загрузятся официальный движок (~24 МБ) и Qwen3-1.7B Q8_0 (~1,8 ГБ). Требуются интернет и примерно 2,5 ГБ свободного места; показываются прогресс и отмена.
4. После установки дождаться «Локальный ИИ готов» и написать вопрос. Далее модель работает офлайн без API-ключа. Старт после простоя автоматический, первый вопрос сохраняется в очереди.
5. Заметки /note, /notes, таймер /timer 30 и кнопка поиска доступны без модели. Интернет нужен для свежего браузерного поиска. Отключение ИИ освобождает память; закрытие программы останавливает её worker.

Автоустановка пакета рассчитана на Windows x64. Сама программа экспортирована, но на настоящей Windows здесь не запускалась: прозрачность, перетаскивание, загрузка, озвучка и захват требуют пользовательской проверки. Минимальное железо ещё не установлено измерениями. Если EXE не запускается, сохранить точный текст/скрин ошибки.

## Реальные возможности

- Семь страниц RU/EN/zh-Hans, встроенный шрифт Noto CJK, локальные заметки/таймеры, пауза и отмена.
- Управляемый локальный CPU-worker: закреплённые URL/версии/хеши, SHA-256, один слот, ограниченные потоки/контекст, авторизованный случайный loopback-порт, остановка и выгрузка по простою.
- Настоящая текстовая нейросеть для первого теста общения и перевода. Это компактный baseline, не финальный интеллект продукта; ответы могут ошибаться. Заявленное качество универсального помощника ещё предстоит подтвердить.
- Ростовой прозрачный native-window прототип с текущей героиней, перетаскиванием, красным переходом и необязательным редким перемещением. Это движение окна и эффекты, **не готовая анимация тела**.
- Необязательное чтение ответов установленными системными голосами. Собственный голос и синхронизация губ не готовы.
- Разовый снимок экрана по кнопке, только в памяти окна просмотра. **Модель снимок пока не анализирует**.
- Явный поиск открывает DuckDuckGo в браузере; результаты ещё не читаются автоматически.

Каталог содержит 113 планируемых событий и 0 законченных художественных клипов. Директор слоёв/приоритетов/прерываний реализован, но риг не создан. Веса не публикуются в git и не входят в маленький Windows ZIP: их получает установщик по явной кнопке.

## Материалы и разработка

OPEN_PREVIEW.html — прежний локальный просмотр концептов; не замена EXE. project.godot — исходники для Godot 4.7.2 standard. После START_WINDOWS.cmd шрифт уже восстановлен; на Linux: python tools/restore_packages.py --font-only. Затем F5.

    python tools/run_checks.py --godot /path/to/godot
    python tools/build_preview.py --godot /path/to/godot --template /path/to/windows_release_x86_64.exe --output ../preview-windows
